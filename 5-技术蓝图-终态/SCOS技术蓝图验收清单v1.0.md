## 4 技术选型一致性

- [ ] 前端采用Vue 3、TypeScript、Vite及常用企业级组件方案。
- [ ] 后端采用Java 17和Spring Boot 3.x。
- [ ] 算法引擎采用Python 3.11和FastAPI。
- [ ] 优化求解器采用SCIP开源求解器，并说明PySCIPOpt或等效调用方式。
- [ ] 算法服务以Docker镜像部署。
- [ ] 每个算法引擎采用独立Docker容器，并允许这些容器共同部署在一台算法服务器上；未设计算法集群、Kubernetes或分布式求解集群。
- [ ] 前端和Java后端部署在算法服务器之外的一台或多台应用服务器上，MySQL原则上独立部署；系统支持多用户并发访问，未把“算法单机部署”误写成“全系统单机部署”。
- [ ] 数据库建议采用MySQL 8.0。
- [ ] 系统间接口优先采用HTTP或HTTPS RESTful API和JSON。
- [ ] 批量文件、人工导入或其他非HTTP方式均说明使用条件和控制措施。
