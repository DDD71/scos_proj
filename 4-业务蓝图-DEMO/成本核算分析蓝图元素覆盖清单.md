# 成本核算分析蓝图元素覆盖清单

| 蓝图或方案元素 | Demo落点 | 交互与验收要点 |
|---|---|---|
| 月末生产批次生成 | 批次和批次谱系管理 | 展示月度任务、数据快照、果葡糖浆/麦芽糖路由版本、批次/谱系版本及生成状态；本页不出现成本字段 |
| 当月全量批次查询 | 当月批次台账 | 277个离线样例批次可按产品线、路由、层级、状态、数据来源、批次号/物料/设备分页查询 |
| 当月全量关系查询 | 上下游关系台账 | 424条关系可按产品线、关系层级、状态、数据来源及上下游批次查询 |
| 任意批次完整链 | 多对多谱系图 | 自动取回所有祖先、后代和关联边；图上节点与边可点击，支持缩放/拖动和相关关系台账跳转 |
| 果葡糖浆批次边界 | 划分规则与台账 | 完整10层；Tw/Tf42/Tf90/Th动态时间窗、F42分叉、F42+F90汇合、罐体与车次物理切分均已落地 |
| 麦芽糖批次边界 | 划分规则与M1/M2/M3样例 | 完整9层；共用前端投料后向M1/M2/M3分流，各线液化、糖化、脱色蒸发、QC和成品罐批次可查 |
| 入厂批次到线边库 | Demo补充关系 | 依入厂日期/车次/供应商ID、WMS移库与线边工位补齐，分流/汇流数量守恒且明确标识“规则补充样例” |
| QC整罐转成品罐 | QC罐→成品罐关系 | 修正版Excel中46条“QC整罐不可拆分”关系原样保留；一个成品罐可汇入多个QC批次 |
| 路由驱动的可变层级 | 路由和批次筛选 | 果葡糖浆10层与麦芽糖9层分别展示，不为不同产线补造虚拟节点 |
| 连续窗口为管理近似 | 谱系节点详情 | 显示边界方法、计量方法、参数、证据和可信度，不宣称精准物理切批 |
| 时间筛选、质量定量 | 谱系关系明细 | 显示转出/接收质量、占比、转化率、方法与证据 |
| QC不合格返工 | 谱系规则和异常 | 只允许QC不合格批通过返工辅助批进入目标新批 |
| 成品罐禁止返流 | 规则引擎自查 | 非法成品罐返流规则自查必须通过，异常时阻止结算 |
| 直接成本归集 | 批次成本管理—直接成本 | 唯一键、来源单据、数量、单价、金额、暂估/实际、目标批次可查询和穿透 |
| 不可直接计批费用 | 直接成本分类结果 | 进入候选费用池，不强制平均到批次 |
| 费用池归集与分摊 | 批次成本管理—费用池 | 来源总额、扣减项、可分摊额、受益范围、首选/备选动因、分母、分摊率、尾差和未分配额 |
| 动因优先级 | 费用池详情 | 实测消耗、设备工时、处理量/绝干量/吨公里、合格产量和审批收入的级次可查 |
| 共享设备受益范围 | 共享QC和设备折旧费用池 | 按实际占用小时和负荷权重分摊，不按名义归属 |
| 分母为零 | 费用池校验 | 无受益批次转停工/闲置池；无首选和备选动因时保持未分配并阻止结算 |
| 上游成本按实际转出量传导 | 批次成本结果 | 每条上游关系成本贡献可查，未转出成本保留在制/库存 |
| 下游批次总成本 | 批次成本构成 | 上游传入+本节点直接+费用池+调整和总成本可勾稽 |
| 正常损耗与异常损失 | 批次成本结果和预警 | 正常损耗由合格产出承担；异常损失转独立对象 |
| 湿基/绝干单位成本 | 批次成本结果 | 口径可切换；分母为0时显示不可用 |
| 制造/完全经营成本 | 批次成本结果和多维分析 | 经营期间费用仅在完全经营视图展示，不回写工序消耗 |
| 生产订单成本聚合 | 批次成本详情/多维分析 | 订单到批次和来源记录可穿透，完工、在制、库存和损失分开 |
| 销售订单成本聚合 | 多维成本和盈利性 | 销售订单→发运批→库存批→生产批→原料批可穿透 |
| 成本异常监测 | 批次成本管理—异常预警 | 原料价格、用量、收率、能耗、单位成本、费用池和低可信度异常均可追溯 |
| 标准-实际差异 | 批次成本管理—差异分析 | 价格、用量、收率、能耗、人工、费用池、交付、暂估转实际和调整可拆解 |
| 迟到/更正数据重算 | 成本差异和规则引擎 | 保留原版本，从最早受影响节点重算下游后代 |
| 成本规则自查和人工复核 | 批次成本管理—规则引擎 | 日常自查、月度复核、异常修正、新规则/结果版本和审计记录 |
| 多维度成本分析 | 多维度成本分析 | 时间范围、订单、SKU、客户、供应商、渠道、区域和两级组合维度 |
| 盈利性分析 | 盈利性分析 | 收入、制造成本、交付成本、完全经营成本、毛利、边际贡献、利润率和单位贡献 |
| 管理决策分析 | 管理决策分析 | 总成本、应收、应付、经营现金流、营运资金、DIO、DSO、DPO和CCC |
| 数量、成本和财务对账 | 月度任务与成本版本 | 一致率、差异原因、状态和财务锁定可查看 |
| 版本和审计 | 全模块 | 数据快照、路由、批次、谱系、规则、成本和分析快照均带版本；历史不覆盖 |
