# 库存优化蓝图元素覆盖清单

## 1 覆盖结论

- 权威蓝图：`SCOS_中粮太仓项目研发模块蓝图方案v1.0.docx`。
- 技术口径：`库存优化模块技术方案_优化版.md` 的服务水平驱动算法，以及已确认的多策略、计划管理、SKU 与共享库容边界。
- Demo 入口：`demo/index.html`。
- 交互形态：业务蓝图仅作为业务逻辑依据；Demo 页面不显示流程图、流程编号、节点数量或需求说明卡片。
- 蓝图库存流程共 5 个、编号节点共 40 个；全部通过实际页面、状态、校验、任务和操作实现，缺失 0 个。
- 逻辑数据实体共 7 类，样例数据均已覆盖。
- 业务范围仅为成品库存；未使用 EOQ、Croston、采购补货或供应商优化算法。ABC 分类仅作为策略配置与统计维度。

## 3 算法与业务规则覆盖

| 技术方案或业务口径 | Demo 实现 |
|---|---|
| 成品可用库存 | 合格库存 − 已分配 − 冻结 − 质量异常；待检未放行不计入 |
| 需求日拆分 | 明确订单日期优先，剩余月计划均摊到无明确订单日期 |
| 策略配置维度 | SKU、物理类目、ABC 分类；优先级为 SKU > 物理类目 > ABC 分类 > 系统默认 |
| 动态策略人工参数 | 目标服务水平 α、完整生产周期 H、检查天数 R、历史窗口 |
| 服务水平与 z-score | `z = Φ⁻¹(α)`；α 表示生产补充周期内不缺货概率 |
| 动态安全库存 | `SS(H)=zσ√H`，`SS(H+R)=zσ√(H+R)` |
| 动态 s/S | 完成当日需求扣减后，`s=ΣD(次日至到货日H天)+SS(H)`；`S=ΣD(次日起H+R天)+SS(H+R)` |
| 静态策略 | 支持安全天数或固定安全库存量；s/S 仍叠加未来 H、H+R 天需求 |
| 补充触发 | 库存位置 `IP≤s` 时，`Qraw=max(0,S−IP)`；可选按最小批量向上取整 |
| 日度递推 | 期初可用 + 当日计划可用入库 + 新增补充到货 − 当日需求 |
| 在途去重 | 日级递推只加载有明确可用日期的计划入库；有效在途保留在月度总量口径，已体现在计划入库中的数量不得再次按默认日期注入 |
| 周度汇总 | 周六至下周五聚合未来 4 周日度补充 |
| 锁定期 | 正式发布日计划后，计划日及之后 6 天共 7 个自然日只预警、不修改；锁定量不可清零，继续参与滚动投影 |
| 策略成效 | 同一需求和生产周期下比较原参数与动态策略：综合库存周转天数下降，28 天投影无频繁缺货，订单满足率保持提升 |
| 阈值可视化 | 模块总览、周计划和日计划的库存推演图均同步展示安全库存 SS、再补货点 s、目标库存 S，使用一致图例与颜色 |
| 共享库容 | 仅果糖 F42、F60、F90 校验共享组；F55 与三类麦芽糖使用独立库存地点 |
| QC 罐 | 不允许一个 QC 罐拆分进入多个成品罐；待检/转罐不重复计入可用库存 |
| 健康度 | 覆盖天数、订单满足率、缺货、超容量、慢动/呆滞/临期及人工原因裁定 |

## 4 计划管理规则覆盖

| 规则 | Demo 实现 |
|---|---|
| 自动创建月计划 | 每月 25 日上游数据就绪后创建下个自然月草稿 |
| 自动创建周计划 | 每周五上游数据就绪后创建下周六至周五草稿 |
| 自动创建日计划 | 每日上游数据就绪后创建自然日草稿 |
| 人工创建 | 选择月/周/日、期间、名称和上游计划 |
| 上游约束 | 周计划必须关联覆盖期间的已发布月计划；日计划必须关联已发布周计划；否则阻断 |
| 计划制定 | 月、周、日分别提供图表、计算明细、系统建议量、人工调整和协同信息 |
| 层级边界 | 月计划不做容量校验；周计划连续推演未来 28 天且不做容量校验；日计划一次制定未来 28 天逐日推荐量和人工计划量，并逐日执行容量校验 |
| 草稿操作 | 可修改、删除、恢复系统建议、保存和提交审批 |
| 审批发布 | 提交后进入待审批；当前 Demo 用户可审批通过或退回 |
| 唯一最终版 | 同层级同期间只保留一个最终发布计划，旧最终版转历史版本 |
| 发布后锁定 | 已发布计划仅可查看，不可直接修改或删除；日计划发布后锁定计划日及之后 6 天，后续草稿重叠日期只读 |
| 关联关系 | 周关联月、日关联周；列表与关系区同时展示 |
| 异常调整 | 先发布异常策略，再按月→周→日替换关联最终版本 |
