4. 重新校准样例数据和预警结果。样例重点展示动态策略在 28 天滚动期内降低库存周转天数、保持高订单满足率且不频繁缺货；仍保留低库存、共享库容和生产承接类预警供演示处置。

## 1 产品定位与目标

Demo 用于呈现库存优化系统实际界面，以及核心用户在系统中的真实操作路径，而不是展示业务蓝图本身。

系统需要支持以下业务闭环：

1. 用户从总览页了解当前成品库存、库存覆盖、库存健康度、未来风险和待办事项，并直接进入处置。
2. 用户在库存策略中为 SKU、物理类目或 ABC 分类选择库存策略，维护有效参数并发布策略版本。
3. 系统按时间点自动创建月、周、日计划草稿；用户也可人工创建并关联已发布的上游计划。
4. 用户进入计划制定工作区，查看系统根据有效库存策略计算的建议，完成调整、协同、提交和审批发布。
5. 重大业务变化发生时，系统形成异常调整任务，引导用户先调整库存策略，再依次重制月、周、日计划。
6. 用户定期复核库存健康度，人工裁定异常原因、填写改进意见，确认并发布健康度报告。

## 2 范围与边界

### 2.1 本期范围

- 仅覆盖成品库存优化。
- 覆盖 7 个样例 SKU：果糖 F42、F55、F60、F90，麦芽糖低 DE、中 DE、高 DE。
- 覆盖模块总览、库存策略、计划管理、策略异常调整、库存健康度五个子模块。
- 支持动态安全库存和静态安全库存两类策略。
- 支持 SKU、物理类目、ABC 分类三级配置；SKU 配置优先于分类配置。
- 支持月、周、日计划创建、修改、删除、制定、提交发布、审批、查看和上下游关联。
- 支持动态 SS/s/S、静态安全库存、周计划和日计划连续 28 天逐日推演、日计划 7 个自然日滚动锁定、日计划容量校验和库存预警。
- 支持健康度原因裁定、改进意见、报告确认与发布。

### 2.2 非范围

- 不展示业务蓝图流程图、流程节点编号或需求说明卡片。
- 不直接创建正式生产任务，不直接改写生产排程。
- 不做供应商选择、采购补货、EOQ 或 Croston 预测。
- ABC 仅作为策略配置和统计维度，不在本期实现自动 ABC 分类模型。
- Demo 中的保存、提交、审批、发布和接口下发均为本地演示状态。

## 3 设计原则

1. **系统工作台导向**：页面围绕“看数据、找异常、做配置、制计划、处理待办”设计。
2. **业务规则内隐**：需求中的规则通过控件、校验、状态和数据自然体现，不设置说明需求的宣传式卡片。
3. **左侧子模块导航**：库存模块展开后显示五个子模块，可展开或收起；不再使用顶部业务流程页签。
4. **操作就地完成**：列表页提供筛选、查看、编辑和动作入口；复杂操作进入详情工作区或弹窗。
5. **建议与人工协同并存**：系统给出默认策略、默认参数和计划建议，用户可在权限范围内调整。
6. **版本与审计**：策略、计划、异常调整和健康报告保留版本、状态、修改人、审批人与时间。
7. **锁定保护**：发布后的策略和计划不可直接修改；计划异常调整需走专门子模块。

## 5 模块功能需求

### 5.1 模块总览

总览页不展示设计说明，呈现用户实际关注的运营信息。

核心指标建议包括：

- 成品可用库存总量。
- 平均库存覆盖天数。
- 未来 7 天预计缺货 SKU 数。
- 低于安全库存 SKU 数。
- 容量利用率及共享库容冲突数。
- 临期、慢动和呆滞库存量。
- 待审批计划数、待处置预警数。

核心区域：

1. **库存水位监控**：按 SKU 展示可用库存、安全库存、再补货点、目标库存、库存覆盖天数和状态。
2. **库存趋势**：展示未来 28 天库存投影，并始终同时展示安全库存 SS、再补货点 s、目标库存 S 三条阈值线；阈值线在总览、周计划和日计划中采用一致的命名、颜色与线型。
3. **预警中心**：缺货、低于安全库存、补充执行偏差、库容、库龄和数据质量预警。
4. **待办事项**：待制定计划、待审批计划、异常调整任务、待发布健康报告。
5. **快速处置**：预警可跳转计划制定、库存策略或策略异常调整，并携带 SKU 和事件上下文。

### 5.2 库存策略

#### 5.2.1 配置维度

用户可按以下维度维护策略：

- SKU。
- 物理类目：果糖类、麦芽糖类。
- ABC 分类：A 类、B 类、C 类。

有效策略优先级为：SKU 配置 > 物理类目配置 > ABC 分类配置 > 系统默认值。界面需展示每个 SKU 当前生效策略及来源。

#### 5.2.2 策略类型

**动态安全库存策略**

用户维护：

- 目标服务水平。
- 完整生产补充周期 H。
- 检查天数 R。
- 历史样本窗口。

系统计算：

```text
zᵢ = Φ⁻¹(αᵢ)
SSᵢ,ds = zᵢ × σᵢ × √Hᵢ
SSᵢ,dS = zᵢ × σᵢ × √(Hᵢ + Rᵢ)
sᵢ,d = ΣD(未来 H 天) + SSᵢ,ds
Sᵢ,d = ΣD(未来 H+R 天) + SSᵢ,dS
Qraw = max(0, Sᵢ,d - IPᵢ,d)，仅在 IPᵢ,d ≤ sᵢ,d 时触发
```

**静态安全库存策略**

用户选择以下一种参数方式：

- 安全天数：`静态安全库存 = 安全天数 × 计划期日均需求`。
- 固定安全库存量：直接维护固定吨数。

静态策略下，s 和 S 仍结合未来需求计算，但安全库存使用固定结果：

```text
sᵢ,d = ΣD(未来 H 天) + SSstatic
Sᵢ,d = ΣD(未来 H+R 天) + SSstatic
```

#### 5.2.3 页面与操作

- 顶部按 SKU、物理类目、ABC 分类、策略类型和状态筛选。
- 策略列表展示 SKU、物理类目、ABC 分类、生效策略、参数摘要、策略来源、版本和状态。
- 系统为每个配置对象提供推荐策略和推荐参数；推荐值有明确“系统建议”标识，但不替代人工确认。
- 用户点击“配置策略”打开侧边或弹窗编辑区；切换策略类型后只显示相应参数。
- 保存生成草稿；确认并发布后形成新有效版本。
- 已发布策略不可在列表中直接修改，需创建新草稿；重大业务变化需进入策略异常调整。
- 用户可打开 SKU 详情查看历史需求、波动、系统计算结果、历史版本和修改审计。

### 5.3 计划管理

#### 5.3.1 计划创建

- 月计划：每月 25 日上游数据准备完成后，创建下个自然月计划草稿。
- 周计划：每周五上游数据准备完成后，创建下周六至周五计划草稿。
- 日计划：每日上游数据准备完成后，创建自然日计划草稿。
- 用户也可人工创建计划。
- 创建周计划必须选择覆盖该期间的已发布月计划。
- 创建日计划必须选择覆盖该日期的已发布周计划。
- 无可关联上游计划时禁止保存，并提示先创建、制定并发布更高层级计划。
- 自动创建只生成草稿，不自动发布。

#### 5.3.2 计划列表

列表支持：

- 按层级、期间、状态、来源和负责人筛选。
- 查看计划 ID、名称、期间、版本、上游计划、策略版本、负责人、状态和更新时间。
- 未发布计划允许制定、修改和删除。
- 待审批计划允许审批通过或退回。
- 正式发布计划允许查看明细，不允许普通修改或删除。

#### 5.3.3 计划制定工作区

点击“制定计划”进入计划工作区。工作区读取最新有效库存策略，并保留本计划使用的策略版本快照。

月计划展示：

- SKU 月需求、有效策略及参数。
- 系统计算的安全库存、再补货点、目标库存和月度建议补充量。
- 月度需求与总量补充趋势，以及低库存、需求波动和生产总量承接风险。
- 月计划不进行共享或独立库容校验，库容约束留到具体日计划中校验。
- 用户可调整未锁定的月度补充建议并填写调整原因。

周计划展示：

- 以计划周周六为起点，一次性向后推演连续 28 天，而不是只展示计划所属的一周。
- 逐日展示需求、期初与期末库存、计划入库、系统建议补充、人工计划量、期望可销售日和风险。
- 同一批 28 天逐日结果按周六至周五汇总为 4 个周段，辅助生产承接和协同。
- 库存推演图同时展示期末库存、SS、s、S、系统建议补货和本版计划量，便于判断补货触发原因与补货后的库存位置。
- 周计划不进行库容校验；用户可调整未锁定建议、记录生产协同意见，第 1 周发布后保持锁定。

日计划展示：

- 以计划日为起点，一次性生成未来连续 28 天的逐日需求、期初/期末库存、计划可用入库、系统推荐补货量和本版计划量，而不是只制定当日补货量。
- 逐日展示动态或静态安全库存、s、S、推荐触发日、期望可销售日和风险结果。
- 每个未锁定日期均提供人工计划量输入，并显示相对系统推荐的调整差异；人工调整后重新推演后续库存。
- 库存推演图同时展示期末库存、SS、s、S、系统推荐补货和本版计划量，阈值线不得因页面迭代或数据校准被省略。
- 对 28 天内每个日期执行共享或独立库容校验，展示通过、剩余容量或超容量缺口。
- 系统在完成计划日当日需求扣减后，以次日至到货日的 H 天需求计算再订货点，并以次日起 H+R 天需求计算目标库存，确保到货日需求峰值纳入补货判断。
- 正式发布日计划后，发布当日及之后 6 天共 7 个自然日锁定；锁定数量继续参与到货和库存投影，不得因锁定而清零。
- 制定新日计划时，与最近已发布日计划锁定窗口重叠的日期只读；锁定窗口外日期可人工调整。新计划正式发布后，按其计划日重新形成 7 天锁定窗口。

工作区提供：

- 保存草稿。
- 恢复系统建议。
- 查看计算说明与数据来源。
- 记录调整原因和协同意见。
- 确认并提交发布审批。

#### 5.3.4 审批与发布

- 用户完成计划制定后点击“确认并提交发布”，计划进入待审批。
- Demo 当前用户具有审批权限，可执行“审批通过并正式发布”或“审批退回”。
- 审批通过后计划正式发布；同层级、同期间只允许一个最终发布版本。
- 日计划审批通过并正式发布时，系统将该计划日及之后 6 天标记为锁定，并保留这 7 天的最终发布补货量。
- 审批退回后计划恢复为可修改草稿，并保留退回意见。
- 正式发布计划可随时查看明细，但不可直接修改。

### 5.4 策略异常调整

触发范围包括重大需求变化、大客户订单增加、长期停机、共享库容变化、完整补充周期变化等。

页面由以下实际工作区组成：

1. **异常事件登记**：事件类型、影响期间、影响 SKU、变化幅度、原因和附件说明。
2. **影响评估**：对库存策略、库存水位、容量和已发布计划的影响。
3. **调整任务清单**：
   - 调整库存策略并发布异常策略版本。
   - 重新制定月计划。
   - 重新制定关联周计划。
   - 重新制定关联日计划。
4. **任务工作台**：点击当前开放任务后进入实际调整页面，而不是直接完成任务。库存策略任务可维护异常参数并查看 SS/s/S 前后变化；月计划可调整月度总量；周计划可调整未来 4 周补充量；日计划可调整未来 28 天逐日补货量并查看容量校验。
5. **任务完成**：用户保存的内容作为调整草稿；只有点击“确认并发布”后才生成异常版本、回写审计记录、完成当前任务并开放下一项任务。
6. **顺序控制**：下一步仅在上一步完成后开放；不可跳过库存策略直接改周或日计划。
7. **版本链**：保留原策略/计划版本、替代版本、上下游关系、操作人、审批人和调整原因。

普通库存波动在总览或日计划中处理，不进入异常调整。

### 5.5 库存健康度

指标包括：

- 平均库存与覆盖天数。
- 库存周转天数。
- 订单满足率。
- 缺货次数。
- 超容量次数。
- 慢动、呆滞和临期库存。
- 计划执行偏差。

页面功能：

- 系统按 SKU 生成指标、健康等级和候选异常原因。
- 用户逐条裁定异常原因，可选择参数设置、需求变化、生产执行、质量冻结、容量限制或其他。
- 用户填写详细改进意见，并选择进入下月策略、进入异常调整或继续观察。
- 保存草稿后，可执行“确认评价结果”。
- 确认后由有权限用户发布健康度报告。
- 报告包含指标、人工原因、改进结论、负责人、跟踪时间和关联任务；发布后不可直接修改。
- 历史报告支持点击查看只读详情，展示报告月份、版本、发布人、发布时间、核心指标、逐 SKU 健康等级、人工裁定原因、改进意见和纳入路径。

## 6 共同业务口径

### 6.1 可用库存与库存位置

```text
成品可用库存 = 合格库存 - 已分配库存 - 冻结库存 - 质量异常库存
库存位置 = 成品可用库存 + 有效在途 + 已锁定或已排程计划入库 - 待满足成品需求
```

待检库存仅在放行并成为可销售库存后计入。

### 6.2 需求拆分

- 有明确出货计划或订单的日期优先使用明确数量。
- 其余月度计划量扣除累计实际和未来明确订单后，平均分摊到无明确订单日期。
- 月、周、日需求不得重复叠加。

### 6.3 库容规则

- 仅果糖 F42、F60、F90 使用共享库容组。
- 果糖 F55和三类麦芽糖使用独立库存地点。
- 容量不足不改写模型原始目标值；系统展示原始建议、容量缺口和可执行量。
- 锁定期容量冲突只预警，不自动削减发布量。
- QC 待检库存和未封罐库存不得作为可销售库存。

## 7 样例数据

样例数据包含：

- 7 个指定成品 SKU，果糖 F55 月需求量最大。
- SKU 物理类目和 ABC 分类。
- SKU、物理类目、ABC 分类的策略配置和系统推荐值。
- 动态与静态安全库存策略样例。
- 历史日需求、样本标准差、明确订单和月计划。
- 合格、已分配、冻结、待检、质量异常库存。
- 共享/独立库存地点、容量和可用状态。
- 月、周、日计划，策略版本快照和上下游关系。
- 库存风险、计划待办、健康度指标、人工原因和改进意见。
- 计划期起点的样例可用库存约覆盖 3.8～4.6 天需求；在不依赖高初始库存的前提下，未来 28 天 7 个 SKU 均不缺货。
- 日级库存递推只加载具有明确预计可用日期的计划入库；有效在途如已包含于这些计划入库，不得再次按默认日期注入。未确定可用日期的在途只参与月度总量平衡，待日期确定后再进入日级投影。

`demo/inventory-demo-data.js` 与 `demo/inventory-demo-data.json` 保持同源。

## 8 交互与视觉要求

- 延续驾驶舱深色视觉体系，但页面内容必须像业务系统，不出现蓝图流程图。
- 不设置用于解释需求的宣传式 KPI 卡；KPI 必须是真实库存指标、风险或待办数量。
- 左侧二级菜单可展开/收起，当前子模块高亮。
- 所有修改操作提供明确反馈；阻断原因必须直接显示。
- 表格支持筛选、查看明细和业务动作。
- 已发布对象的修改、删除按钮不可用或不显示。
- 图表与表格在 1440×900 和 1920×1080 下无页面级横向溢出。
- 页面控制台无阻断性错误；原驾驶舱其他模块导航保持可用。
