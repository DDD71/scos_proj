# 采购优化蓝图元素覆盖清单

## 1 依据与边界

- 业务节点依据：`SCOS_中粮太仓项目研发模块蓝图方案v1.0.docx` 采购优化四条流程。
- 算法依据：`采购优化模块技术方案.md`。
- 冲突处理：采购优化求解不读取库存和排程、不计算具体供货日期；蓝图中相关旧表述不进入求解工作台，合同、订单和到货状态仅在执行追踪中展示。

## 2 蓝图节点映射

### 2.1 月度采购方案制定

| 蓝图节点 | 系统实现 |
|---|---|
| 10 形成待采购需求 | 新建方案选择已发布需求版本，读取玉米淀粉当期需求并支持人工调整 |
| 20 生成月度采购建议 | 校验候选池及报价后，按技术方案生成最优和次优供应商采购组合 |
| 30 评审并调整采购方案 | 比较推荐方案、查看成本拆解、人工选择方案和调整求解参数 |
| 40 确认采购方案 | 校验需求完全覆盖、供应能力、供应商数、必选供应商和占比约束 |
| 50 审批月度采购方案 | 当前 Demo 用户可提交审批并执行审批通过操作 |
| 60 发布已确认采购方案 | 发布版本并锁定输入快照、参数、方案、意见和审批记录 |
| 70 进入采购执行 | 发布后形成 E采/SAP 执行依据，但不自动创建合同或采购订单 |
| 原料保障能力看板 | 采购方案列表页汇总当前玉米淀粉在库、在途、在手合同未释放量和合计，并按7个成品SKU的日均生产量与淀粉单耗折算可支撑生产天数；只作决策参考，不进入MILP求解 |
| 报价单邮件推送 | 报价步骤向当前候选池一键邮件推送标准CSV报价单，发送前展示收件人、截止时间和模板字段，发送后记录协同状态 |
| 报价单上传 | 支持选择标准CSV回传文件，校验供应商编码、候选池归属、字段及数据类型，预览后确认导入报价并更新回传状态 |

| 蓝图节点 | 系统实现 |

### 2.5 新增需求：大宗原料价格预测提报

| 新增需求 | 系统实现 |
|---|---|
| 子模块位置 | 在采购优化左侧子菜单中位于“供应商资料库”下方 |
| 覆盖时间 | 选择开始、结束月份以及月、季度、年度颗粒度，最细到自然月 |
| 期间互斥 | 同一原料、同一月份只允许一种已发布预测方式；不同方式的预测期间重叠时阻止发布并提示冲突编号与期间 |
| 直接价格 | 逐颗粒度维护元/吨预测价格，以紫色实线整合进“玉米淀粉历史价格及同环比价格对比”主图 |
| 涨跌幅 | 维护相对上一颗粒度的涨跌幅，保留原始百分比，并基于提报基准价逐期复合换算参考价后，以粉色虚线整合进同一主图 |
| 数值预测连线 | 首段数值预测连接最近一期历史采购均价；相邻数值预测区间即使切换提报方式也共享边界锚点连续绘制，只有纯趋势或无数值月份才保留断点 |
| 仅趋势 | 维护方向、强度、判断把握和分月依据；采购方案以独立“定性趋势判断”区块补充主图无实际预测值的月份，直接展示月度方向卡片，不再展示概括性走势横幅，不生成具体价格 |
| 提报记录分区 | “定性趋势判断”和“已发布预测提报”分为两个独立区块；定性趋势在上，全部已发布提报记录在下并可进入原始明细 |
| 状态管理 | 支持新建、编辑、保存/删除草稿、查看和发布；已发布版本只读 |
| 采购方案联动 | 引用方案月及后续六个月内已发布且有效的预测区间；显示编号、范围、方式、提报人、发布时间、摘要和原始明细入口 |
| 模型边界 | 预测用于询价、锁价和采购时机参考，不替代供应商有效报价，不自动修改 MILP 目标函数或约束 |

## 3 技术方案覆盖

| 技术要点 | Demo 实现 |
|---|---|
| 有效报价 | 候选供应商报价有效期和完整性校验 |
| 账期资金成本 | `报价 × 年化资金成本率 × 账期 / 365` |
| 包装袋回收抵扣 | 直接维护元/吨抵扣，缺失按 0 处理 |
| 综合成本目标 | 报价 + 运费 - 账期资金节省 - 包装袋回收抵扣 |
| 采购需求量约束 | 所有供应商分配量之和等于确认需求量 |
| 供应能力约束 | 单家分配不超过本期最大可供量 |
| 最少供应商数 | 参数可维护，求解时硬约束校验 |
| 供应商占比 | 支持入选最低占比和单家最高占比 |
| MILP 决策变量 | 显式建立整数采购量 `x_i` 和二元供应商选择变量 `y_i` |
| MILP 联动约束 | 使用 `x_i` 与 `y_i` 的上下界约束连接供应商选择、MOQ、占比和最大可供量 |
| 启发式求解 | 使用贪心构造产生初始解，并执行供应商 Add、Drop、Swap 邻域搜索 |
| 小规模精确校验 | 候选供应商不超过 18 家时检查全部供应商组合并显示启发式最优性差距 |
| 多方案推荐 | 对启发式与精确校验得到的可行解去重，按综合成本输出最优和次优方案 |
| 同成本排序 | 供应商数量更少优先，再参考质量、准时率和风险分 |
| 价格变化趋势 | 在同一张元/吨价格图中叠加期货价、采购均价及其上月、上年同期价格曲线，并继续向未来月份叠加直接提报预测和涨跌幅折算预测，不使用变化率 |
