### 1.1 需求来源与依据

### 1.2 产品定位与目标

供应链驾驶舱是 SCOS 的**战略决策与指挥中枢**，位于功能分层的「第一层：数据基石与决策中枢」。它不是独立的数据采集系统，而是基于其他模块（采购、库存、排程、成本、追溯）的**数据和运算结果**，通过多层级、可配置、可视化的方式，为管理层至执行层提供全局供应链状态的"一站式"视图。

驾驶舱要达成三个核心目标：

1. **态势感知透明化**：将"产销—储运—环保—资金"各环节的运行状态实时、统一地呈现，消除信息孤岛。
2. **决策支持数据化**：所有指标由系统数据自动计算、实时/准实时更新，为战略与战术决策提供量化依据。
3. **异常响应实时化**：主动识别并预警异常，支持从预警一键钻取到根因，快速发起处置，最终支撑"产销—储运—环保—资金"的**实时闭环管理**。

### 1.3 范围与边界

**模块包含（In Scope）**：

- 全局态势总览视图（核心 KPI 卡片）
- 全局供应链地图（GIS 地图、节点分布、在途车辆）
- 专题分析子视图（产销 / 储运 / 环保 / 资金）
- 智能预警与事件管理中心（分级预警、预警联动）
- 情景模拟与决策支持（沙盘推演）
- KPI 与看板的钻取溯源
- 个性化看板自定义配置（拖拽式）
- 移动端核心 KPI 监控与预警推送

**模块不包含（Out of Scope）**：

- 数据的采集、清洗与存储管道（由统一数据服务层 / 实时数据平台承担，见标书第四章、第六章）
- 优化模型的计算引擎（排程、采购、库存、成本等计算由各自模块承担，驾驶舱只消费结果）
- 主数据、事务数据的录入维护（驾驶舱只读展示，杜绝手工录入指标）
- 预警规则的业务触发逻辑归属各业务模块，驾驶舱负责**集中展示、分级与联动跳转**

### 1.4 产品原则

1. **角色导向**：提供可自定义视图，满足上级管理公司领导、总经理、总监、工厂调度员等不同角色的关注点。
2. **数据驱动**：所有指标必须由系统数据自动计算、实时/准实时更新，杜绝手工录入。
3. **可视化优先**：综合运用图表、图形、地图、颜色编码和动画，使复杂数据易于理解。
4. **钻取溯源**：支持从 KPI 总览到明细业务数据的逐层钻取，快速定位问题根源。
5. **预警与预测**：不仅展示现状，更主动预警异常，并提供基于数据的趋势预测。

## 3. 信息架构与导航

驾驶舱作为 SCOS 的默认首页（决策中心下的首个模块），采用以下信息架构：

```
供应链驾驶舱
├── 顶部：全局态势总览（5 个核心 KPI 卡片）
├── 中部左：全局供应链地图（GIS）
├── 中部右：实时预警中心（迷你预警面板）
├── 中部下：多维运营分析（标签页：产销 | 储运 | 环保 | 资金）
├── 下部：智能预警中心（全量预警面板）
├── 下部：情景模拟推演（沙盘推演）
└── 全局：数据更新时间、刷新、导出报告、个性化配置入口
```

**导航交互规则**：

- KPI 卡片、地图节点、预警条目均为**可点击**元素，点击进入对应钻取视图或模块。
- 「产销 / 储运 / 环保 / 资金」四个标签页可自由切换；支持用户将某个专题视图"固定"为默认页。
- 顶部提供「保存策略」「导出报告」「个性化配置」等全局操作入口。

## 4. 功能需求

> 优先级说明：P0 = 必须（标书底线要求）；P1 = 重要；P2 = 可选增强。

### 4.1 全局态势总览视图（核心 KPI 卡片）

**功能描述**：在界面顶部以最醒目的方式展示全供应链核心实时 KPI，让管理层在数秒内掌握全局态势。

**核心 KPI 卡片（P0）**：系统必须预置以下 5 个核心 KPI，并支持后续配置扩展：

| KPI | 单位 | 说明 | 计算逻辑（详见 5.1） |
|---|---|---|---|
| 今日产销达成率 | % | 当日产量对计划的达成 | 今日实际产量 ÷ 今日计划产量 |
| 成品库存周转天数 | 天 | 成品库存健康度 | 平均成品库存 ÷ 日均出库量 |
| 订单准时交付率（OTD） | % | 交付履约质量 | 按期交付订单数 ÷ 应交付订单数 |
| 供应链总运营成本 | 万元 | 今日/当月累计全链成本 | 采购+生产+库存+物流+环保+资金成本汇总 |
| 现金循环周期 | 天 | 资金运营效率 | DIO + DSO − DPO |

**交互与展示要求**：

- 每张卡片展示：指标名称、当前值、环比/同比变化（▲/▼ + 变化量），变化方向用绿涨红跌（成本类、周期类指标反色）标色。
- 卡片按角色可配置显示顺序与显隐；点击卡片进入该指标的钻取分析视图。
- 数据更新频率：关键运营类 KPI ≤ 5 秒（详见 8.1）。

**验收要点**：5 个核心 KPI 均自动计算、无手工录入；卡片支持点击钻取；变化趋势与数据更新时间可见。

### 4.2 全局供应链地图（GIS）

**功能描述**：基于 GIS 地图，可视化展示供应商、工厂、仓库、客户的地理分布，实时动态显示在途车辆位置与状态，通过颜色编码快速标识各节点健康状态。

**详细需求**：

1. **节点分布展示（P0）**：在地图上展示以下四类节点的地理分布，节点类型用不同图标区分：
   - 供应商（可下钻查看绩效评分、供应状态）
   - 工厂（可下钻查看产线状态、产能负荷）
   - 仓库（可下钻查看利用率、库存量）
   - 客户（可下钻查看订单、交付状态）

2. **在途车辆实时动态（P0）**：实时显示在途车辆位置、车牌/车型、货物（品类+数量）、目的地、预计到达时间，以及状态（正常 / 延迟 / 预警）。位置数据每 ≤ 5 秒刷新。

3. **节点健康状态颜色编码（P0）**：用红、黄、绿标识节点健康状态：

| 颜色 | 含义 | 典型触发 |
|---|---|---|
| 🟢 绿 | 正常 | 库存合理、生产正常、按时交付 |
| 🟡 黄 | 预警 | 库存过高/过低、发货延迟、能耗超标 |
| 🔴 红 | 紧急 | 生产中断、关键原料断供、重大质量事故 |

4. **运输线路展示（P1）**：展示"供应商→工厂→仓库"的运输线路，支持高亮指定线路。

5. **地图交互（P1）**：支持缩放、拖拽、节点点选、框选；点击节点弹出信息卡片并可钻取；与数字孪生/厂区管理平台预留空间态势集成接口（见 7.2）。

**验收要点**：四类节点分布正确；在途车辆位置与状态 ≤ 5 秒更新；红黄绿编码准确反映节点健康状态；节点可点击钻取。

### 4.3 专题分析子视图（可配置标签页）

**功能描述**：提供"产销 / 储运 / 环保 / 资金"四个可自由切换或组合的专题视图，对应"产销—储运—环保—资金"四大闭环管理维度。

#### 4.3.1 "产销"协同视图（P0）

| 子项 | 展示内容 | 图表类型 |
|---|---|---|
| 需求 vs 产量 | 每日/每周需求预测与实际产量曲线对比 | 双轴折线图 / 柱线组合图 |
| 产线排产与进度 | 各产线排产计划与实际进度，高亮瓶颈工序与延迟订单 | 进度条 + 甘特图（简版） |
| 原料匹配 | 原料（玉米淀粉）库存与未来 7 天生产消耗的匹配度 | 仪表盘 / 面积图 |

- 瓶颈工序与延迟订单用红色高亮，点击可钻取至精益生产排程模块。
- 原料匹配度低于阈值时，联动触发预警（关联安全库存/采购模块）。

#### 4.3.2 "储运"效率视图（P0）

| 子项 | 展示内容 | 图表类型 |
|---|---|---|
| 全网库存 | 原料库、在制品库、成品库的库存量与库龄结构 | 堆叠柱状图 / 瀑布图 |
| 仓库热度图 | 各仓库吞吐量及利用率 | 热力图 / 散点图（地图叠加） |
| 物流效能看板 | 车辆满载率、在途时效、运输成本等 | KPI 数字卡 + 趋势图 |

- 库存可按库龄区间（如 0–7 天 / 8–30 天 / 30 天以上）下钻至 SKU。
- 物流效能指标与 TMS/车辆路径规划模块联动。

#### 4.3.3 "环保"合规与效能视图（P0）

| 子项 | 展示内容 | 图表类型 |
|---|---|---|
| 能耗指标 | 吨产品耗水、耗电、耗汽 | 折线图 / 柱状图 |
| 环保指标 | 废水排放量、COD 浓度、SS 浓度、氨氮等，与国家标准限值对比预警 | 对比柱状图（实际值 vs 国标限值） |
| 能源成本关联 | 能源成本与产量的关联关系 | 散点图 / 相关性图 |

- 环保指标超标或接近限值时，用红色/黄色标识并触发预警，关联环保/EMS 数据源。

#### 4.3.4 "资金"效率视图（P0）

| 子项 | 展示内容 | 图表类型 |
|---|---|---|
| 应收/应付账龄 | 应收账款与应付账款账龄分析 | 堆叠柱状图 / 瀑布图 |
| 库存资金占用 | 库存资金占用情况，可下钻到具体物料品类 | 饼图 / 树图 / 条形图 |
| 产品边际贡献 | 产品边际贡献率，高利润与负利润产品结构 | 柱状图 / 瀑布图（利润瀑布） |

- 资金数据权威源为中粮 SAP 系统（见 7.2），驾驶舱只读展示。
- 账龄区间、资金成本口径与统计与成本核算分析模块保持一致。

**验收要点**：四个专题视图可自由切换/组合；各视图指标齐全、图表类型符合；数据可逐层钻取至明细。

### 4.4 智能预警与事件管理中心

**功能描述**：集中显示所有由系统规则引擎触发的预警信息，实行分级管理，支持从预警一键关联至相关业务模块进行根因分析与方案调整。

#### 4.4.1 统一预警面板（P0）

- 集中显示全系统预警，支持按类型（设备故障 / 原辅料 / 库存 / 订单 / 能耗等）过滤、按时间/级别排序。
- 每条预警展示：级别、标题、描述、触发时间、业务类型、关联模块跳转按钮。

#### 4.4.2 分级预警机制（P0）

| 级别 | 颜色 | 定义 | 典型场景 |
|---|---|---|---|
| 一级 | 🔴 红色 | 紧急 | 产线故障停机、关键原料断供、重大质量事故 |
| 二级 | 🟡 黄色 | 警告 | 库存低于安全库存、订单交付即将延迟、能耗超标 |

- 三级及以下提示信息（蓝色/信息类）可作为辅助提示，不进入紧急预警面板首屏。

#### 4.4.3 预警联动（P0）

- 点击任一预警，可一键关联至相关模块（全程追溯 / 生产排程 / 采购 / 库存 / 成本）进行根因分析和方案调整。
- 支持从预警直接发起处置动作（如"冻结相关批次库存""调整排程"），动作下发至对应模块并跟踪闭环状态。
- 重大质量追溯预警应向驾驶舱发送高级别警报（由全程追溯模块触发）。

**验收要点**：预警集中展示、分级正确；预警可一键联动跳转；处置动作可跟踪闭环。

### 4.5 情景模拟与决策支持（沙盘推演）

**功能描述**：提供"沙盘推演"功能，允许用户修改关键参数，快速看到对全局的影响，为决策提供量化依据。

**典型情景（P0，需预置）**：

| 情景 | 可调参数 | 输出影响 |
|---|---|---|
| 需求波动 | 大客户订单增减比例（如 +20%） | 对产能、原料库存和交付日期的影响 |
| 供应风险 | 供应商延迟交货天数（如 7 天） | 生产计划调整建议、是否启动备用供应商 |
| 成本优化 | 原料价格波动（如 ±15%） | 对采购/运营总成本的影响 |

**交互与输出要求**：

- 参数以滑杆/输入框调整，点击"运行模拟"后，用**雷达图/对比图**展示"当前 vs 模拟"在关键指标上的差异。
- 预置快捷情景按钮（如"旺季压力""供应中断""价格下跌"），一键载入参数组合。
- 模拟结果可导出报告，不直接修改正式数据（只读推演）。

**验收要点**：三类典型情景可运行；模拟结果可视化对比；模拟不影响正式业务数据。

### 4.6 钻取溯源

**功能描述**：支持从 KPI 总览到明细业务数据的逐层钻取，快速定位问题根源。

**钻取链路要求（P0）**：

1. KPI 卡片 → 专题视图 → 明细清单 → 源单据/工单。
2. 预警条目 → 关联模块 → 根因分析 → 处置动作。
3. 地图节点 → 节点详情 → 关联业务明细。

- 钻取响应时间 ≤ 2 秒（见 8.2）。

**验收要点**：关键 KPI 和预警均支持逐层钻取至明细；钻取路径清晰可回溯。

### 4.7 自定义配置与个性化看板

**功能描述**：最终用户可通过"拖、拉、拽"等方式，无需编码即可自定义个性化看板。

**配置能力要求（P0）**：

1. **组件库**：提供 KPI 卡片、图表、地图、表格、预警面板等标准组件，供拖拽组合。
2. **布局自定义**：拖拽调整组件位置、尺寸；支持保存为个人/团队/角色模板。
3. **指标配置**：从预置指标库选择展示指标、设置阈值与刷新频率。
4. **角色模板**：按角色预置默认看板，用户可在其上调整并另存为个人视图。
5. **恢复默认**：一键恢复角色默认看板。

**验收要点**：非技术用户可在无编码情况下完成看板增删改、拖拽布局并保存。

### 4.8 移动端视图

**功能描述**：提供对主流移动设备（手机、平板）的友好支持，至少提供核心 KPI 监控和预警推送的移动端视图。

**移动端范围（P0 底线 / P1 增强）**：

**验收要点**：移动端可查看核心 KPI 与预警；预警可实时推送；适配手机与平板。

## 6. UI/UX 设计理念与交互规范

> 标书要求：阐述设计如何符合用户习惯、降低认知负荷。

### 6.1 设计理念

1. **一屏全局（Overview First）**：首屏用 5 个 KPI 卡片 + 地图 + 迷你预警，让决策者在数秒内形成全局认知，细节随需下钻。
2. **颜色即语义（Color = Meaning）**：红/黄/绿三色贯穿健康状态、预警分级、趋势涨跌，统一语义，降低学习成本。
3. **减少认知负荷**：每屏信息密度适中，先总览后明细，避免信息过载；复杂数据用图表而非表格优先呈现。
4. **钻取而非跳转（Drill, Don't Switch）**：尽量在驾驶舱内完成钻取，减少跨模块页面切换与人工核对。
5. **角色适配（Role-based）**：默认视图按角色裁剪，只展示该角色关心的数据，减少干扰。

### 6.2 视觉规范（与现有原型一致）

- **主题**：深色科技风（dark theme），以蓝、青、绿、黄、紫区分指标类别。
- **KPI 卡片**：五色区分（蓝=产销、青=库存、绿=交付、黄=成本、紫=资金）。
- **图表引擎**：ECharts（地理坐标、雷达、柱线、饼图、热力图等）。
- **字体/密度**：数据用等宽字体（JetBrains Mono/Orbitron 风格），保证数字可读性。

### 6.3 交互规范

| 交互 | 规范 |
|---|---|
| 数据刷新 | 顶部显示"数据更新于 HH:MM"，提供手动刷新按钮 |
| 全局操作 | 保存策略、导出报告、个性化配置置于顶部统一入口 |
| 悬停提示 | 图表 hover 显示 tooltip 明细 |
| 空/异常态 | 数据缺失或异常时显示明确占位与提示，不展示误导性数据 |

## 7. 数据与接口需求

### 7.1 数据获取原则

- 驾驶舱**只消费**统一数据服务层 / 实时数据平台提供的标准数据，自身**不包含**独立的数据采集、清洗、存储管道（标书第四章、第六章）。
- 所有指标由系统数据自动计算，杜绝手工录入。
- 与底层数据平台及其他业务模块通过 **RESTful API** 交互，确保数据完整性与一致性。

### 7.2 核心接口

| 数据/能力来源 | 接口方式 | 提供给驾驶舱的内容 |
|---|---|---|
| 统一数据服务层 | RESTful API | 主数据、交易数据、聚合分析数据（KPI 基础数据） |
| 实时数据平台 | 消息订阅 | 产量、发货量、储罐液位、产线状态、车辆位置等实时指标 |
| 采购/库存/排程/成本/追溯模块 | RESTful API / 事件总线 | 各模块计算结果与预警事件 |
| SAP | API | 财务、资金、成本类指标（权威数据源） |
| 数字孪生 / 厂区管理平台 | 专用 API + 事件流 | 空间元数据、业务态势流（三维可视化联动） |

### 7.3 数据一致性

- 资金类数据权威源明确指定为中粮 SAP 系统，与 SAP 的财务数据同步逻辑、频次及对账机制需在设计中说明并经甲方确认。
- 驾驶舱展示的指标与各业务模块输出保持同源一致，避免口径分歧。

### 8.1 数据实时性

## 10. 待确认事项与风险

### 10.1 待确认事项

1. **资金类数据口径**：现金循环周期（DSO/DPO）、供应链总运营成本的归集口径与 SAP 的映射关系，需与财务及 SAP 实施方对齐。
2. **地图与数字孪生边界**：驾驶舱 GIS 地图与"数字孪生及厂区管理平台"三维可视化的分工与集成深度，需明确是轻量二维地图还是复用数字孪生引擎。
3. **预警分级阈值**：一级/二级预警的具体业务阈值（如安全库存倍数、能耗超标百分比）需由业务方确认并在规则引擎配置。
4. **角色默认视图**：上级管理公司领导的具体可见范围与指标集合，需与甲方统一身份认证系统角色映射确认。
5. **移动端推送渠道**：预警推送采用 APP 推送/短信/邮件中哪一种或组合，需确认。

### 10.2 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 数据源接口未就绪 | 指标无法自动计算 | 提前确定统一数据服务层接口清单，驾驶舱做数据缺失降级展示 |
| 实时数据延迟不达标 | 关键 KPI 超过 5 秒 | 采用消息订阅 + 缓存，关键指标走实时数据平台专用通道 |
| 地图/第三方服务中断 | GIS 视图不可用 | 降级为节点列表 + 预警面板，核心监控不中断 |
| 成本/资金数据敏感 | 越权泄露 | 行级/列级权限 + 审计留痕 |
