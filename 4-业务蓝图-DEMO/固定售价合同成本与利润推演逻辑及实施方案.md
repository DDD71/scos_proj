## 2. 场景定位

### 2.1 业务问题

客户签订半年或一年固定售价合同后，销售单价不随原材料行情调整。履约期间，玉米淀粉价格和产线负荷发生变化，产品单位成本、单位利润以及合同未来收益随之变化。

本场景回答四个问题：

1. 每吨产品成本从多少变为多少？
2. 每吨预计履约利润从多少变为多少？
3. 所选推演期合同预计利润增加或减少多少？
4. 在这组条件下，合同是盈利、保本还是亏损？

### 2.2 用户操作原则

```text
选择销售合同
  → 统一或按月滑动、输入玉米淀粉价格涨跌幅 -100%～+100%
  → 统一或按月滑动、输入产能负荷 50%～100%
  → 开始推演
  → 查看成本、利润与月度过程
  → 可选：比较其他假设或导出报告
```

只有原料价格变化和产能负荷两个推演变量。合同是业务对象，不计入变量数量。成本数据、交付量和计量口径由系统带入；推演起点由系统确定，时长可在合同剩余期限内选择。

### 2.3 核心简化前提

页面参数区持续显示一句说明：

> 按合同计划交付量测算，从下月起，最晚至合同结束；未校验该负荷下的交付能力。

本场景按合同可按计划履约的前提测算成本和利润。负荷率只用于查取单位加工成本，不改变合同交付数量，不计算产量不足或额外生产收入。

“产能负荷”指合同产品所在产线或适用生产单元的负荷，不是某一份合同占产能的比例。推演结果也不构成调整产线负荷的可执行建议。

## 3. 范围与边界

### 3.1 本期范围

- 在现有三个场景后增加第四个场景。
- 单次选择一份固定售价、单产品销售合同。
- 第一版仅模拟玉米淀粉价格，合同选择自动带出关联产品和产线。
- 以 100%、70%、50% 三档历史单位加工成本为参考点；支持 50%～100% 滑动调节和数字输入，步长 1%。
- 使用基线与模拟完全相同的分月交付量。
- 从业务快照下个月起，到合同结束月止，按月展示。
- 展示四个核心结果、月度时间轴、成本利润趋势、简短原因解释。
- 支持恢复默认、取消、参数变更后结果失效、同合同情景比较和报告导出。
- 样例覆盖半年与一年合同；所有结果由参数和样例数据计算。

### 3.2 本期不做

- 原料库存消耗、成品库存结转及采购锁价到期的成本滞后。
- 采购供应商优化、合同重新议价、真实行情预测。
- 负荷变化下的生产排程、交付缺口、加班、外购及违约损失。
- 修改销售数量、销售单价、原料耗用率或其他成本。
- 用户自定义生效日期。原料涨跌和负荷均支持按合同月份逐月设置。
- 多原料联动、多产品合同、跨合同产能分配。
- 已履约部分重算、全合同历史与未来合并、企业净利润或现金流预测。
- 自动生成采购单、工单、审批任务或采纳方案。

此前讨论过的库存与锁价缓冲、保本原料价格反推、复杂利润分层和履约能力检查，不进入本期操作界面及计算模型。

## 4. 输入设计

### 4.1 用户可操作项

| 操作 | 控件 | 拟定设置 | 行为 |
|---|---|---|---|
| 销售合同 | 下拉选择 | 至少两份有效 Mock 合同 | 带出客户、产品、产线、固定售价、期间、基线负荷和推演量 |
| 推演时长 | 月数输入框、“至合同结束”按钮 | 1～合同剩余月数，默认至到期月 | 不允许超期；切换合同恢复其完整剩余期限；修改后结果失效 |
| 玉米淀粉价格变化 | “统一涨跌 / 按月设置”切换；滑块与数字输入框同步 | -100%～+100%，步长 1%，默认统一 +15% | 各月相对基准原料价计算，不逐月累乘；显示模拟原料单价；空值、非整数和超界输入阻止运行 |
| 产能负荷 | “统一负荷 / 按月设置”切换；滑块与数字输入框同步联动 | 50%～100%，步长 1%，默认统一 70% | 按月模式每月独立设置；相邻历史档位之间分段线性插值；空值、非整数和超界输入提示月份并阻止运行 |

这些范围和默认值为实施建议，可在配置中维护，不硬编码在多个渲染函数中。

原料价格示例：`上涨 15% · 3,000 → 3,450 元/吨`。

负荷控件旁显示原负荷，下方显示模拟单位加工成本，例如：`原负荷 100% · 模拟负荷 70%`。单位加工成本明细放入折叠说明，不新增输入表单。

原料与负荷独立选择统一或按月模式。首次进入按月模式，以对应统一值填充各月；两项均按月时合并在同一月份卡片，显示月份、计划交付量、原料涨跌、模拟原料单价、产能负荷和加工成本。原料与负荷分别提供“全部设为 X%”按钮，批量填充不影响另一变量。两种模式切换保留当前合同的月度组合；切换合同重新初始化该合同月份，避免沿用其他合同配置。恢复默认回到默认合同、原料 +15%、统一负荷 70%。

### 4.2 系统带入的数据

| 数据 | 说明 |
|---|---|
| 合同信息 | 合同号、客户、产品、产线、合同起止日期、固定销售单价 |
| 业务基线 | 固定快照日期、推演起止月份、各月计划交付量 |
| 原料基线 | 玉米淀粉基准单价、每吨合格产品对应的玉米淀粉耗用量 |
| 加工基线 | 原产能负荷，以及 100%、70%、50% 的单位加工成本 |
| 其他成本 | 固定的单位包装、交付等成本，必须与加工成本互斥 |
| 版本信息 | 数据快照、历史成本参考版本、计算模型版本 |

不直接使用成本分析模块某个历史订单的总成本替代本场景的成本拆分。现有已结算订单也不能直接当作未来长协合同，需要新增独立 Mock 合同数据。

### 4.3 时间与数量边界

- 时间按样例业务快照计算，不根据打开页面当天的系统时钟滚动。
- 推演起点为快照下个月与合同开始月两者中较晚的月份。
- 推演终点由所选月数确定，默认合同结束月，最大不得超过合同到期月；只纳入所选月份的合同计划交付量，不补造合同外月份。
- 合同本月尚未交付部分不进入本次推演，不能把推演量误标为全部未履约量。
- 页面显示完整年月，例如 `2026-11—2027-04`；结果说明明确“所选 N 个月的履约”，避免将缩短时段的金额标为全部剩余合同金额。
- 第一版样例采用完整自然月；真实合同有月中起止日期时，以已给定的该月合同交付量为准，不按整月天数放大。
- 无未来月份或未来交付总量为零的合同不可运行，显示“无可推演的后续交付”。

## 5. 历史负荷成本口径

### 5.1 历史数据如何简化

每个产品与适用产线维护三档历史单位加工成本，前端运行时在参考点查表，其他负荷按相邻参考点分段线性插值，不在页面临时求解费用池或固定费用分摊。

历史数据准备时统一产品规格、质量和计量基准，剔除主要原料费用，并明确加工成本是否含人工、能耗、折旧及制造费用。已含在加工成本中的项目不得再计入其他成本。

历史单位加工成本按“该档位可比样本加工成本总额 ÷ 对应合格产量总额”归集，不能直接平均不同产量样本的单位成本。需保留样本期间和数据版本。真实历史不足时采用明确标注的 Mock 配置，不宣称为实际统计结果。

### 5.2 本期采用的简化模型

| 负荷 | 样例单位加工成本 | 业务解释 |
|---|---:|---|
| 100% | 300 元/吨 | 样例满载单位加工成本 |
| 70% | 358 元/吨 | 样例低负荷下能耗和固定费用分摊增加 |
| 50% | 440 元/吨 | 样例负荷进一步下降，单位加工成本继续增加 |

这组数据用于演示低负荷成本上升，并非所有产线都必须满足该趋势。正式数据按实际历史维护。50%～70% 与 70%～100% 分段线性插值，不超出区间外推，也不将档位成本再次除以负荷率。

```text
K(L) = K(L低) + [K(L高) - K(L低)] × (L - L低) / (L高 - L低)
```

例如本表中 85% 负荷的单位加工成本为 329 元/吨，60% 为 399 元/吨；70%、50%、100% 的原结果保持一致。

### 5.3 原料与单位基准

- 原料价格、销售价格和成本统一采用人民币不含税口径。
- 原料单价单位为元/吨原料；产品售价和单位加工成本为元/吨合格成品。
- 原料耗用系数单位为吨原料/吨合格成品，需注明所采用的湿基或绝干基准。
- 系数已含相应收率与正常损耗，不再另乘损耗系数。
- 第一版固定耗用系数；负荷变化引起的材料收率变化暂不纳入。
- 原料基价、加工成本与其他成本必须边界清楚。运输费用在何处归集由数据定义固定，不能重复计入。

## 6. 计算逻辑

### 6.1 变量定义

| 变量 | 含义 |
|---|---|
| P | 固定销售单价，元/吨成品 |
| R0 | 基线玉米淀粉单价，元/吨原料 |
| rm | 第 m 月原料涨跌率，以小数参与计算；统一模式各月相同 |
| a | 单位成品原料耗用量，吨原料/吨成品 |
| L0、Lm | 基线负荷、第 m 月模拟负荷（统一模式下各月相同） |
| K(L) | 对应负荷的单位加工成本，元/吨成品 |
| O | 固定其他单位成本，元/吨成品 |
| Qm | 第 m 个月计划交付量，吨成品 |

### 6.2 基线与模拟

```text
第 m 月模拟原料单价 Rm = R0 × (1 + rm)

基线单位成本 C0 = a × R0 + K(L0) + O
第 m 月模拟单位成本 Cm = a × Rm + K(Lm) + O

基线每吨利润 U0 = P - C0
第 m 月模拟每吨利润 Um = P - Cm

第 m 月收入 = Qm × P
第 m 月基线成本 = Qm × C0
第 m 月模拟成本 = Qm × Cm
第 m 月基线利润 = Qm × U0
第 m 月模拟利润 = Qm × Um

推演期基线利润 = 各月基线利润之和
推演期模拟利润 = 各月模拟利润之和
利润变化额 = 推演期模拟利润 - 推演期基线利润
合同加权单位成本 = 各月模拟成本之和 / 推演期交付总量
合同加权每吨利润 = 推演期模拟利润 / 推演期交付总量
```

利润变化额小于零显示“减少”，大于零显示“增加”，等于零显示“无变化”。不能把负利润截断为零，不能沿用现有库存场景的非负指标约束。

### 6.3 成本变化归因

```text
加权原料价 = Σ[Qm × Rm] / ΣQm
原料影响（元/吨） = a × (加权原料价 - R0)
加权加工成本 = Σ[Qm × K(Lm)] / ΣQm
负荷影响（元/吨） = 加权加工成本 - K(L0)
单位成本变化 = 原料影响 + 负荷影响

合同利润变化 = -单位成本变化 × 推演期交付总量
```

原料与负荷影响可以一正一负，必须保留符号。结论依据两者合计，不能只因原料上涨就固定显示“利润下降”。

第一版不设置独立归因图，采用结果下的一句说明即可；详细公式放入“数据与计算说明”。

### 6.4 盈利状态

优先判断合同加权模拟每吨利润，再判断相对基线的变化：

| 条件 | 状态 |
|---|---|
| 模拟每吨利润 < 0 | 预计亏损 |
| 模拟每吨利润 = 0 | 预计保本 |
| 模拟每吨利润 > 0，且低于基线 | 利润下降 |
| 模拟每吨利润 > 0，且高于基线 | 利润提升 |
| 模拟每吨利润 > 0，且等于基线 | 保持盈利 |

状态卡同时给出数值，避免仅凭颜色判断。若基线已经亏损而模拟亏损收窄，主状态仍为“预计亏损”，补充说明“较基线亏损减少”。

各月采用相同耗用；按月模式依据当月原料价与负荷计算单位成本及利润，可以出现部分月份盈利、部分月份亏损。合同状态展示整体结果，另显示有交付且月度利润小于零的月份数。零交付月份不计入亏损月数；单位成本曲线仍展示该月负荷对应的成本。

### 6.5 数值与汇总

- 内部采用统一精度策略；单价与单位成本计算到至少四位小数，最终展示元保留两位、万元保留两位。
- 建议使用定点整数或统一金额取整函数，避免各渲染位置各自舍入。
- 月度收入与成本计算后统一到分，月度利润取两者之差；期间利润从月度利润求和。
- 归因计算允许因月度舍入出现分级尾差，校验中给出明确容差，不按已展示的万元数字反推总额。
- 状态判定与用户可见的单位利润两位小数保持一致，避免显示 0.00 元却标记亏损。

## 7. 可复算演示案例

### 7.1 样例基线

| 参数 | 数值 |
|---|---:|
| 合同号 | SC-DEMO-F55-001 |
| 客户与产品 | 示例饮料客户 A / 果糖 F55 |
| 合同期间 | 2026-11-01—2027-04-30，半年合同 |
| 业务快照 | 2026-10-11 |
| 固定销售单价 P | 3,200 元/吨成品 |
| 基线玉米淀粉价格 R0 | 3,000 元/吨原料 |
| 原料耗用系数 a | 0.8 吨原料/吨成品，仅为 Mock 系数 |
| 基线负荷 L0 | 100% |
| 单位加工成本 K(100/70/50) | 300 / 358 / 440 元/吨 |
| 其他单位成本 O | 100 元/吨 |
| 每月交付量 | 1,000 吨 |
| 推演交付总量 | 6,000 吨 |

基线单位成本为 `0.8 × 3,000 + 300 + 100 = 2,800 元/吨`，每吨利润为 `400 元`，半年推演期利润为 `240 万元`。

### 7.2 情景结果

| 假设 | 原料价 | 加工成本 | 单位总成本 | 每吨利润 | 推演期利润 | 相对基线利润变化 |
|---|---:|---:|---:|---:|---:|---:|
| 无变化：0%、100%负荷 | 3,000 | 300 | 2,800 | 400 | 240 万元 | 0 |
| 仅原料上涨 15%、100%负荷 | 3,450 | 300 | 3,160 | 40 | 24 万元 | -216 万元 |
| 仅负荷降到 70%、原料不变 | 3,000 | 358 | 2,858 | 342 | 205.20 万元 | -34.80 万元 |
| 默认：原料上涨 15%、70%负荷 | 3,450 | 358 | 3,218 | -18 | -10.80 万元 | -250.80 万元 |
| 原料上涨 10%、70%负荷 | 3,300 | 358 | 3,098 | 102 | 61.20 万元 | -178.80 万元 |
| 原料下降 10%、50%负荷 | 2,700 | 440 | 2,700 | 500 | 300 万元 | +60 万元 |

表中单价与成本单位为元/吨，原料价对应吨原料，其余对应吨成品。

默认结果说明：

> 玉米淀粉上涨 15%，产能负荷由 100% 降至 70%，每吨成本增加 418 元，其中原料影响 360 元、负荷影响 58 元；每吨利润由 400 元降至 -18 元，推演期剩余履约预计亏损 10.80 万元。

默认每月收入 320 万元、模拟成本 321.80 万元、模拟利润 -1.80 万元。月度单位成本是水平线，累计利润逐月下降，不制造原料耗尽或锁价到期事件。

另配置一份十二个月单产品合同，使用独立的售价、耗用系数、基线负荷和分月交付数据，验证切换对象后确实读取新基线。该样例至少包含不均匀交付月份和一个零交付月份。

## 8. 页面和交互方案

### 8.1 场景入口与配置区

- 第四个场景标签显示“原料价格与生产负荷”，现有三个场景保留。
- 保持现有暗色风格和场景选择方式；标签较长时允许换行，窄屏不横向撑破容器。
- 配置区保留合同选择，原料和负荷分别提供统一与按月设置；滑块与数字输入框同步，默认不展开月度编辑区。另提供合同期内月数输入，展示到期日与最大可选月数。
- 合同摘要显示客户、产品、固定售价、推演月份和交付总量。
- 成本场景隐藏 7/14 天切换，改为只读“按月推演至合同结束”。回到旧场景恢复此前日度时域。
- 不增加库存、锁价、费用池或日期配置入口。

### 8.2 结果区

结果按以下顺序展示：

1. 一句总体判断，例如“每吨利润由 400 元降至 -18 元，推演期预计亏损 10.80 万元”。
2. 四张结果卡：每吨成本、每吨利润、推演期合同预计利润、盈利状态。按月模式前两项标明“加权”，按交付量加权；状态卡附亏损月份数。金额卡展示基线、模拟和变化。
3. 月份播放区：当前月份、当月交付量、当月收入、当月成本、当月利润；明确属于按计划交付的测算。
4. 一张月度趋势图：固定售价、基线单位成本、模拟单位成本，单位统一为元/吨成品。成本高于售价的月份明确标记。
5. 一句成本变化解释，拆出原料和负荷的贡献。
6. 折叠的“月度明细与报告”：当月原料涨跌、原料单价、负荷、单位成本、单位利润、交付量、收入、基线/模拟成本、基线/模拟利润、模拟累计利润，以及比较、导出按钮。
7. 折叠的“数据与计算说明”：假设、负荷成本表、来源、快照和模型版本。

四张卡片展示整段推演结果，不随时间轴切换改变；播放区展示所选月份数据，趋势图高亮同一月份。成本场景不复用水罐库存动画，不显示“库存耗尽”“日末库存”或“未来 7 天”等日度文案。

### 8.3 播放与状态

- 支持播放、暂停、上一月、下一月和拖动月份时间轴，沿用现有速度控件。
- 运行完成后从首月开始；遵守系统减少动态效果设置，不强制自动播放。
- 拖动时间轴或单步切换时暂停播放，最后一个月停止。
- 修改参数、切换合同、切换场景或离开沙盘时，停止播放并释放本场景图表。
- 修改参数后上一次当前结果立即失效，需要再次点击运行；历史比较快照不随之改变。
- 切换合同保留统一原料涨幅和统一负荷；按月模式分别用对应统一值初始化新合同的月份，刷新合同摘要和基线；“恢复默认”恢复本场景默认合同及 +15%、统一 70%。
- 取消运行后不发布结果；防止旧运行在取消或场景切换后回写页面。

### 8.4 月度解释规则

解释内容由同一份结果数据生成，包括当月交付量、单位利润和月度利润。零交付月份显示“本月无计划交付，收入、成本与利润均为 0”；累计利润保持上月值。

两项均统一时单位成本各月相同；任一项按月时按各月原料价格和负荷计算，播放、图表及说明使用该月的单位成本和利润。合同加权指标不替代月度指标。

### 8.5 情景比较与导出

- 成本场景最多保留三个可比结果，只比较同一合同、同一快照、相同时域、相同基线与模型版本的不同参数。
- 成本结果与原三个库存/交付场景分组保存，不放进同一张指标表。
- 比较列标题显示原料涨跌与负荷的完整组合，各自相邻相同数值合并为月份区间；展示加权单位成本、加权单位利润、推演期利润和盈利状态。统一模式与按月模式可以互相比对。
- 切换合同后只显示当前合同对应的比较组；不会将另一份合同套用当前基线。
- 加入比较时深拷贝结果及基线，不能只保存对可变对象的引用。
- 导出沿用现有 TXT 报告形式，包含合同、快照、月份、参数、四项结果、月度明细、归因、模型版本和计算前提。
- 报告必须由保存的结果快照生成，不重新读取当前控件或已变动的合同配置。
- 比较结果仅在当前浏览器页面会话中保存；不宣传为数据库持久化结果库。

## 12. 校验与验收

### 12.1 计算验收

| 用例 | 预期 |
|---|---|
| 原料变化 0%，负荷等于合同基线 | 基线与模拟完全一致；不能把 70% 误认为所有合同的零冲击负荷 |
| 第 7 节六组样例 | 成本、每吨利润、期间利润和归因与表格一致 |
| 原料降价、负荷下降共同作用 | 正负影响正确抵消，不固定生成下降文案 |
| 单位利润等于零 | 状态为预计保本；可用内部精确输入或专用合同样例验证，无需增加 UI 控件 |
| 负利润 | 页面、图表、累计利润、比较和报告保留负号 |
| 不均匀月度交付 | 月度总额随数量变化，单位成本不伪造变化 |
| 零交付月份 | 当月收入、成本、利润为零，累计值保持不变 |
| 基线负荷为 70% 的另一合同 | 查取正确基线档位，避免默认套用 100% |
| 重复运行 | 除运行 ID、时间和审计时间外，数值和结论一致 |
| 汇总与归因 | 月度金额与期间金额勾稽；成本归因与利润变化在约定舍入容差内一致 |

### 12.2 数据与异常验收

- 校验合同 ID、日期、月度月份唯一性、月度数量非负、有限数值和完整成本档位。
- 滑块范围外、非法负荷、NaN、Infinity、缺失基线负荷值时禁止运行，给出具体原因。
- 原料耗用系数和基准价格应为有效正值；模拟原料价允许在 -100% 时为零，其他成本允许零，不将缺失数据默认替换为零。
- 明确填零的无交付月份与缺失月度数据不同；缺失月份提示数据不完整，不静默当作零。
- 合同已结束、没有下月及以后交付、推演总量为零时不生成利润结论。
- 页面快照、报告快照、样例业务日期和月度期间一致，刷新按钮不会把固定样例伪装成新的真实数据。

### 12.3 交互验收

- 首屏仅一个合同选择、一个价格滑块、一组负荷滑块与数字输入框，没有额外必填配置。
- 新场景按月展示，旧场景继续使用 7/14 天切换。
- 参数或合同变化后当前结果失效；取消和切换后旧运行不能回写。
- 月份播放、暂停、拖动、单步、末月停止和减少动态效果均正常。
- 四项汇总与月度过程区含义明确，零交付月份不显示亏损事件。
- 比较最多三个结果，只显示相同合同和基线；修改当前参数不改变历史比较结果。
- 导出报告逐项对应当前运行结果，跨合同切换不会混用数据。
- 数据缺失时显示错误状态而非空白页面或看似有效的零成本。
- 桌面和窄屏控件可用，负荷控件有明确选中状态，图表负值不被裁剪。

### 12.4 原三个场景回归

检查客户增单与交期变化、供应商到货延迟、生产能力下降的：参数、7/14 天切换、运行与取消、库存动画、时间轴、恢复默认、比较、导出及离开页面停止播放。

重点检查 `旧场景 → 成本 → 另一旧场景 → 成本` 的连续切换，不能出现月/日标签混用、旧图表残留、定时器重复或利润被旧 KPI 逻辑截为零。

### 12.5 验证方式

- 对纯计算函数编写少量有意义的数值验证，覆盖本节关键边界与第 7 节可复算样例。
- 浏览器实际操作完成新场景验收与三个旧场景回归，检查控制台错误及导出文件内容。
- 当前 `utils/check_integrity.py` 仍使用旧驾驶舱路径，不以它通过或失败作为本轮验收结论；本轮直接验证当前入口及新增资源。
- 不把本文档编写时的静态阅读记录当作功能测试通过；实施后单独记录执行结果。
