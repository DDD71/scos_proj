# 固定售价合同成本与利润推演逻辑及实施方案

> 用途：梳理新增成本推演场景的业务逻辑、页面交互、计算规则和代码实施步骤，供业务、产品、研发确认。
> 状态：v2.4 已实施并通过计算与浏览器验收，2026-10-12。保持成本计算口径不变，将麦芽糖 M2 Mock 合同售价调整为 3,300 元/吨。
> 数据说明：金额、数量及负荷成本为 Mock 样例，用于演示计算与交互，不代表客户实际合同或生产数据。

## 0. 本轮修改记录（v2.4）

本轮在 v2.3 成本口径基础上，仅调整麦芽糖样例合同售价。本节是 v2.4 的最高优先级规则，若与后文历史记录冲突，以本节及第 14.11 节为准。

- 产能负荷不改变原料移动加权价、BOM 耗用系数和单位原料成本；负荷只影响单位加工成本。
- BOM 耗用系数的乘法仅用于计量单位换算：原料价格是“元/吨原料”，乘以“吨原料/吨成品”后，得到“元/吨成品”的单位原料成本，该过程与产能负荷无关。
- 生产区将单位成本拆成三列：“预计单位原料成本”、“单位加工成本”和“预计单位生产成本”，三者可直接勾稽。
- 麦芽糖 M2 Mock 销售合同的固定售价由 v2.3 的 3,500 元/吨下调为 3,300 元/吨；原料价格、BOM、加工成本和履约节奏保持不变。

- 预计单位生产成本严格等于“每吨成品已耗用原料成本 + 单位加工成本”，不再叠加“其他单位成本”。
- F55 Mock 销售合同的固定售价由 3,200 元/吨调整为 3,500 元/吨，使样例定价与原料及加工成本更匹配。
- 期末未耗用的玉米淀粉仅作为原料库存资产结转，其金额不进入本销售合同的销售成本和利润；合同销售成本只结转实际履约成品已耗用的原料成本与加工成本。

- 销售合同总量由系统带入，用户可以重新分配各月销售履约量；各月销售计划合计必须等于合同总量，否则禁止运行。
- 系统根据合同总量和产品 BOM 耗用系数计算玉米淀粉总采购需求：`总采购需求 = 合同总量 × 单位成品玉米淀粉耗用量`。
- 用户可以分别调整各月玉米淀粉采购量和采购单价；各月采购量合计必须等于系统折算的总采购需求，否则禁止运行。
- 页面显式展示销售量到玉米淀粉需求的折算比例：`a 吨玉米淀粉 / 吨成品`，并同时展示便于业务理解的反向产出能力 `1 吨玉米淀粉可生产 1/a 吨成品`。
- 生产侧用户只维护各月产能负荷，不直接维护计划生产量。负荷只用于计算单位加工成本，负荷越低，单位加工成本越高；页面实时展示每月负荷对应的单位加工成本和预计单位生产成本。
- 月度计划生产量由系统计算。设当月期初剩余原料加当月采购形成累计可用原料：若可覆盖当月履约销量，则计划生产量等于当月履约销量；若不足，则计划生产量等于累计可用原料按 BOM 折算后可生产的成品量。
- 采购节奏不需要逐月覆盖销售节奏。原料到货晚导致计划生产不足时，当月未满足的销售计划记为“放弃销量”，不自动顺延；未耗用原料作为期末库存结转。
- 月度推演按原料移动加权成本、生产入库成本和成品移动加权成本逐月结转，使用实际履约量计算收入、销售成本和利润；同时展示计划销售、实际履约、放弃销量、采购、生产及期末库存。
- 配置区提供合同与 BOM 摘要、销售总量校验、采购总量校验，并按业务顺序拆分为销售节奏、采购节奏与价格、生产负荷与系统计划三个清晰区域；不提供“错配演示”按钮，结果只由用户当前输入计算。

## 2. 场景定位

### 2.1 业务问题

客户签订半年或一年固定售价合同后，销售单价不随原材料行情调整。履约期间，玉米淀粉价格和产线负荷发生变化，产品单位成本、单位利润以及合同未来收益随之变化。

本场景回答四个问题：

1. 合同总量如何按月履约，各月实际能完成多少销量？
2. 根据 BOM 折算出的玉米淀粉总采购需求是多少，采购量和价格如何安排？
3. 在用户给定销售、采购和负荷方案后，系统按累计可用原料能形成多少计划生产量，哪些月份会放弃销量、形成多少期末原料库存？
4. 在这组节奏和价格下，合同实际收入、销售成本和利润是多少？

### 2.2 用户操作原则

```text
选择销售合同
  → 调整各月销售履约量（合计必须等于合同总量）
  → 查看 BOM 折算的玉米淀粉总采购需求
  → 调整各月采购量与采购单价（采购量合计必须等于总采购需求）
  → 调整各月产能负荷并查看对应单位加工成本
  → 系统按履约需求与累计可用原料计算各月计划生产量和预计单位生产成本
  → 开始推演
  → 查看实际履约、放弃销量、库存结转、收入、成本与利润
  → 可选：比较其他假设或导出报告
```

合同是业务对象。用户维护销售节奏、采购数量与价格、生产负荷三组月度数据；系统负责总量守恒、BOM 折算、计划生产量、库存结转和经营结果计算。

### 2.3 核心简化前提

页面参数区持续显示一句说明：

> 合同总量和 BOM 总采购需求必须守恒；计划生产量由履约需求与累计可用原料共同决定，无法按月履约的部分计为放弃销量。

生产负荷是生产侧的月度业务假设，不由计划产量反算，也不改变系统按原料可用量计算的计划生产量；其唯一传导方向是单位加工成本：负荷降低，固定成本摊薄变差，单位加工成本升高。推演结果不直接下发采购订单、生产工单或销售交付计划。

## 3. 范围与边界

### 3.1 本期范围

- 在现有三个场景后增加第四个场景。
- 单次选择一份固定售价、单产品销售合同。
- 第一版仅模拟玉米淀粉价格，合同选择自动带出关联产品和产线。
- 以 100%、70%、50% 三档历史单位加工成本为参考点；用户按月维护负荷，系统查取或插值得到单位加工成本。
- 销售计划、采购数量、采购价格和产能负荷按合同月份维护；计划生产量为系统计算结果。
- 合同销售总量守恒；采购总量等于 BOM 折算总需求；计划生产量逐月由履约销量与累计可用原料计算。
- 逐月计算原料库存、成品库存、实际履约和放弃销量。
- 从业务快照下个月起，到合同结束月止，按月展示。
- 展示四个核心结果、月度时间轴、成本利润趋势、简短原因解释。
- 支持恢复默认、取消、参数变更后结果失效、同合同情景比较和报告导出。
- 样例覆盖半年与一年合同；所有结果由参数和样例数据计算。

### 3.2 本期不做

- 采购锁价到期、供应商选择、采购订单执行、合同重新议价与真实行情预测。
- 跨合同产能竞争、日级排程、加班、外购及违约损失。
- 修改销售单价、BOM 耗用率或产线月产能基线。
- 用户自定义合同外月份；节奏只能在合同月份内调整。
- 多原料联动、多产品合同、跨合同产能分配。
- 已履约部分重算、全合同历史与未来合并、企业净利润或现金流预测。
- 自动生成采购单、工单、审批任务或采纳方案。

保本原料价格反推、复杂利润分层、违约罚金和跨合同资源竞争不进入本期操作界面及计算模型。

## 4. 输入设计

### 4.1 用户可操作项

| 操作 | 控件 | 拟定设置 | 行为 |
|---|---|---|---|
| 销售合同 | 下拉选择 | 至少两份有效 Mock 合同 | 带出客户、产品、产线、固定售价、期间、基线负荷和推演量 |
| 月度销售履约量 | 月度表格数字输入 | 非负数 | 合计必须等于销售合同总量；未满足的当月计划在结果中记为放弃销量 |
| 月度玉米淀粉采购量 | 月度表格数字输入 | 非负数 | 合计必须等于合同总量乘 BOM 耗用系数 |
| 月度玉米淀粉采购价 | 月度表格数字输入 | 大于 0，元/吨原料 | 当月采购入库进入原料移动加权成本，不使用简单涨跌率代替 |
| 月度产能负荷 | 月度表格数字输入 | 50%～100%，整数 | 用户唯一可维护的生产侧变量；决定对应月份的单位加工成本，不直接改变计划生产量 |

这些范围和默认值为实施建议，可在配置中维护，不硬编码在多个渲染函数中。

页面按顺序展示三段：①销售节奏表维护月度履约销量；②采购节奏与价格表维护月度玉米淀粉采购量和采购价；③生产负荷与系统计划表维护月度负荷，并只读展示系统计划生产量、对应单位加工成本和预计单位生产成本。顶部同步展示折算比例、销售总量差异和采购总量差异；差异不为零时阻断运行。仅提供“恢复合同基线”，不提供预置的“错配演示”。

| 数据 | 说明 |
|---|---|
| 合同信息 | 合同号、客户、产品、产线、合同起止日期、固定销售单价 |
| 业务基线 | 固定快照日期、合同总量、合同月份、基线月度履约节奏 |
| BOM 基线 | 玉米淀粉物料编码、每吨合格产品对应的玉米淀粉耗用量、BOM 版本 |
| 采购基线 | 基准采购单价及月度采购节奏 |
| 加工基线 | 原产能负荷，以及 100%、70%、50% 的单位加工成本 |
| 产能基线 | 合同产品所在产线的月产能 |
| 版本信息 | 数据快照、历史成本参考版本、计算模型版本 |

不直接使用成本分析模块某个历史订单的总成本替代本场景的成本拆分。现有已结算订单也不能直接当作未来长协合同，需要新增独立 Mock 合同数据。

### 4.3 时间与数量边界

- 时间按样例业务快照计算，不根据打开页面当天的系统时钟滚动。
- 推演起点为快照下个月与合同开始月两者中较晚的月份。
- 推演覆盖合同所有剩余月份，不补造合同外月份；销售和采购总量校验均以该合同剩余总量为准。
- 合同本月尚未交付部分不进入本次推演，不能把推演量误标为全部未履约量。
- 页面显示完整年月，例如 `2026-11—2027-04`；结果说明明确属于合同剩余月份推演。
- 第一版样例采用完整自然月；真实合同有月中起止日期时，以已给定的该月合同交付量为准，不按整月天数放大。
- 无未来月份、合同总量为零、销售总量不平或采购总量不平时不可运行，并显示具体差额。

## 5. 历史负荷成本口径

### 5.1 历史数据如何简化

每个产品与适用产线维护三档历史单位加工成本，前端运行时在参考点查表，其他负荷按相邻参考点分段线性插值，不在页面临时求解费用池或固定费用分摊。

历史数据准备时统一产品规格、质量和计量基准，剔除主要原料费用，并明确加工成本覆盖人工、能耗、折旧及制造费用。本场景不在加工成本之外额外叠加其他单位生产成本。

历史单位加工成本按“该档位可比样本加工成本总额 ÷ 对应合格产量总额”归集，不能直接平均不同产量样本的单位成本。需保留样本期间和数据版本。真实历史不足时采用明确标注的 Mock 配置，不宣称为实际统计结果。

### 5.2 本期采用的简化模型

| 负荷 | 样例单位加工成本 | 业务解释 |
|---|---:|---|
| 100% | 300 元/吨 | 样例满载单位加工成本 |
| 70% | 358 元/吨 | 样例低负荷下能耗和固定费用分摊增加 |
| 50% | 440 元/吨 | 样例负荷进一步下降，单位加工成本继续增加 |

这组数据用于演示低负荷成本上升，并非所有产线都必须满足该趋势。正式数据按实际历史维护。50%～70% 与 70%～100% 分段线性插值，不超出区间外推，也不将档位成本再次除以负荷率。

```text
K(L) = K(L低) + [K(L高) - K(L低)] × (L - L低) / (L高 - L低)
```

例如本表中 85% 负荷的单位加工成本为 329 元/吨，60% 为 399 元/吨；70%、50%、100% 的原结果保持一致。

### 5.3 原料与单位基准

- 原料价格、销售价格和成本统一采用人民币不含税口径。
- 原料单价单位为元/吨原料；产品售价和单位加工成本为元/吨合格成品。
- 原料耗用系数单位为吨原料/吨合格成品，需注明所采用的湿基或绝干基准。
- 系数已含相应收率与正常损耗，不再另乘损耗系数。
- 第一版固定耗用系数；负荷变化引起的材料收率变化暂不纳入。
- 单位原料成本按 `原料移动加权价（元/吨原料） × BOM 耗用系数（吨原料/吨成品）` 计算，结果单位为“元/吨成品”。BOM 乘法是单位换算，不是负荷修正。
- 预计单位生产成本只由单位原料成本和单位加工成本组成。运输等费用如已进入原料入库价或加工成本，不得再重复计入。

## 6. 计算逻辑

### 6.1 变量定义

| 变量 | 含义 |
|---|---|
| P | 固定销售单价，元/吨成品 |
| Qcontract | 销售合同剩余总量，吨成品 |
| a | 单位成品原料耗用量，吨原料/吨成品 |
| Qraw | 系统折算的玉米淀粉总采购需求，吨原料 |
| Sm | 第 m 月计划销售履约量，吨成品 |
| Bm、Rm | 第 m 月采购量与采购单价，吨原料、元/吨原料 |
| Pm | 第 m 月系统计划生产量，吨成品；不是用户输入 |
| Lm | 第 m 月用户设定的产能负荷，50%～100% |
| K(L) | 对应负荷的单位加工成本，元/吨成品 |
| ARm / AFm | 月末原料库存量与原料库存金额 |
| AGm / GFm | 月末成品库存量与成品库存金额 |
| Ym | 第 m 月实际履约量，吨成品；本期等于系统计划生产量 |
| Dm | 第 m 月放弃销量，吨成品 |

### 6.2 基线与模拟

```text
Qraw = Qcontract × a
ΣSm = Qcontract
ΣBm = Qraw

原料到货后移动加权价 RawWACm = (AFm-1 + Bm × Rm) / (ARm-1 + Bm)
累计可用原料 AvailableRawm = ARm-1 + Bm
累计可用原料可生产量 RawCapacitym = AvailableRawm / a
系统计划生产量 Pm = min(Sm, RawCapacitym)
原料耗用量 = Pm × a
原料耗用成本 = 原料耗用量 × RawWACm
用户设定产能负荷 Lm ∈ [50%, 100%]
单位加工成本 = K(Lm)
预计单位原料成本 UnitRawm = RawWACm × a
预计单位加工成本 UnitProcessm = K(Lm)
预计单位生产成本 = UnitRawm + UnitProcessm
当月生产成本 = 原料耗用成本 + Pm × K(Lm)

成品入库后移动加权价 FGWACm = (GFm-1 + 当月生产成本) / (AGm-1 + Pm)
实际履约量 Ym = min(Sm, AGm-1 + Pm)
放弃销量 Dm = Sm - Ym
销售成本 = Ym × FGWACm
收入 = Ym × P
利润 = 收入 - 销售成本

ARm = ARm-1 + Bm - Pm × a
AFm = AFm-1 + Bm × Rm - 原料耗用成本
AGm = AGm-1 + Pm - Ym
GFm = GFm-1 + 当月生产成本 - 销售成本

推演期实际履约量 = ΣYm
推演期放弃销量 = ΣDm
推演期收入 / 成本 / 利润 = 各月收入 / 销售成本 / 利润之和
本合同销售成本 = 已履约成品结转的已耗用原料成本 + 加工成本
期末剩余原料价值 = AFm（作为库存资产结转，不计入本合同销售成本）
实际履约加权单位成本 = 推演期销售成本 / 推演期实际履约量
实际履约加权每吨利润 = 推演期利润 / 推演期实际履约量
```

销售与采购总量为强校验。生产侧不能直接覆盖系统计划生产量；某月累计可用原料不足时，系统自动将计划生产量限制为原料可生产量，缺口计为放弃销量且不自动回补。负荷只影响 `UnitProcessm`，不改变 `RawWACm`、`a` 或 `UnitRawm`，不作为产量上限，也不能把负利润截断为零。

### 6.3 成本变化归因

页面将经营影响拆成三部分：销售节奏决定月度履约需求；采购价和采购节奏决定可用原料与原料移动加权成本；用户设定的产能负荷决定单位加工成本。系统根据销售需求和累计可用原料计算计划生产量，再计算履约与利润。结论必须同时说明履约率、放弃销量、期末原料库存与利润，不能只依据采购单价或负荷判断盈利变化。

### 6.4 盈利状态

优先判断是否存在放弃销量，再判断实际履约利润：

| 条件 | 状态 |
|---|---|
| 放弃销量 > 0 且利润 < 0 | 履约不足且亏损 |
| 放弃销量 > 0 且利润 ≥ 0 | 履约不足 |
| 放弃销量 = 0 且利润 < 0 | 全量履约但亏损 |
| 放弃销量 = 0 且利润 = 0 | 全量履约并保本 |
| 放弃销量 = 0 且利润 > 0 | 全量履约并盈利 |

状态卡同时展示实际履约量、履约率与放弃销量，避免“利润为正”掩盖未履约。零实际履约月份收入与销售成本为零，但采购和生产形成的库存金额必须继续结转。

### 6.5 数值与汇总

- 内部采用统一精度策略；单价与单位成本计算到至少四位小数，最终展示元保留两位、万元保留两位。
- 建议使用定点整数或统一金额取整函数，避免各渲染位置各自舍入。
- 月度收入与成本计算后统一到分，月度利润取两者之差；期间利润从月度利润求和。
- 归因计算允许因月度舍入出现分级尾差，校验中给出明确容差，不按已展示的万元数字反推总额。
- 状态判定与用户可见的单位利润两位小数保持一致，避免显示 0.00 元却标记亏损。

## 7. 可复算演示案例

### 7.1 样例基线

| 参数 | 数值 |
|---|---:|
| 合同号 | SC-DEMO-F55-001 |
| 客户与产品 | 示例饮料客户 A / 果糖 F55 |
| 合同期间 | 2026-11-01—2027-04-30，半年合同 |
| 业务快照 | 2026-10-12 |
| 固定销售单价 P | 3,500 元/吨成品 |
| 月度玉米淀粉采购价 | 3,000 / 3,050 / 3,150 / 3,200 / 3,100 / 3,000 元/吨原料 |
| 原料耗用系数 a | 0.8 吨原料/吨成品，仅为 Mock 系数 |
| 月产能 / 基线负荷 | 1,250 吨 / 80% |
| 单位加工成本 K(100/70/50) | 300 / 358 / 440 元/吨 |
| 月度销售 / 系统计划生产量 | 各 1,000 吨 |
| 合同总量 / BOM 采购总需求 | 6,000 / 4,800 吨 |

基线六个月全部履约：实际履约 6,000 吨，销售收入 2,100 万元，销售成本 1,683.20 万元，合同利润 416.80 万元，期末原料与成品库存均为零。由于月度采购价格不同，各月利润不同。

### 7.2 情景结果

用户可手工将首月 800 吨采购调整为 0，并将末月采购从 800 吨调整为 1,600 吨，销售仍保持每月 1,000 吨。系统据此计算首月累计可用原料为 0，计划生产量为 0；第 2～6 月各按履约需求生产 1,000 吨。推演期实际履约 5,000 吨、放弃销量 1,000 吨，期末保留玉米淀粉 800 吨（价值 240 万元）。该期末原料作为库存资产结转，不计入本合同销售成本；本情景销售成本仅为已履约 5,000 吨所耗用的原料成本与加工成本。该结果完全由用户输入产生，页面不提供预置“错配演示”。

用户还可将任意月份负荷从 80% 调至 50%。计划生产量和履约量在原料充足时保持不变，但单位加工成本由插值结果上升至 440 元/吨，预计单位生产成本同步上升，合同利润下降。该例用于验证“负荷只影响单位成本，不直接改变产量”的业务口径。

另配置一份十二个月单产品合同，使用独立的售价、耗用系数、基线负荷和分月交付数据，验证切换对象后确实读取新基线。该样例至少包含不均匀交付月份和一个零交付月份。

## 8. 页面和交互方案

### 8.1 场景入口与配置区

- 第四个场景标签显示“原料价格与生产负荷”，现有三个场景保留。
- 保持现有暗色风格和场景选择方式；标签较长时允许换行，窄屏不横向撑破容器。
- 配置区保留合同选择，按业务顺序拆成三个明确区域：①销售节奏，②采购节奏与价格，③生产负荷与系统计划。
- 合同摘要显示客户、产品、固定售价、合同期间和合同总量。
- 配置区顶部提供四张勾稽卡：销售合同总量、销售转玉米淀粉折算比例、BOM 折算采购总需求、系统计划生产合计。折算卡同时显示 `a 吨原料/吨成品` 与 `1/a 吨成品/吨原料`。销售与采购差额为零时显示通过，非零时显示红色差额并阻断推演。
- 销售节奏表只编辑月度履约销量；采购节奏与价格表只编辑月度采购量和采购单价；生产负荷与系统计划表只编辑产能负荷，并实时只读显示系统计划生产量、预计单位原料成本、对应单位加工成本和预计单位生产成本。
- 仅提供“恢复合同基线节奏”。不提供“错配演示”或其他预置情景按钮，最终推演结果只依据当前用户输入。
- 成本场景隐藏 7/14 天切换，改为只读“按月推演至合同结束”。回到旧场景恢复此前日度时域。
- 不增加库存、锁价、费用池或日期配置入口。

### 8.2 结果区

结果按以下顺序展示：

1. 一句总体判断，包含履约状态、实际履约率和合同利润。
2. 五张结果卡：实际履约量、销售收入、销售成本、合同利润、期末库存（玉米淀粉 / 成品）。
3. 一句经营解释，明确合同总量、实际履约、放弃销量、期末库存及收入成本利润。
4. 月份播放区：当前月份、计划销售、采购、系统计划生产、产能负荷、单位加工成本、预计单位生产成本、实际履约、放弃销量、收入、成本和利润。
5. 一张月度趋势图：销售收入、销售成本以柱状图展示，利润以折线展示，单位统一为万元。
6. 折叠的“月度经营明细与报告”：完整展示计划、实际、库存、收入、成本、利润和累计利润，并提供比较、导出按钮。
7. 折叠的“数据与计算说明”：合同总量、BOM、产能、负荷成本表、库存计价规则、来源、快照和模型版本。

五张卡片展示整段推演结果，不随时间轴切换改变；播放区展示所选月份数据，趋势图高亮同一月份。成本场景不复用水罐库存动画，不显示“未来 7 天”等日度文案。

### 8.3 播放与状态

- 支持播放、暂停、上一月、下一月和拖动月份时间轴，沿用现有速度控件。
- 运行完成后从首月开始；遵守系统减少动态效果设置，不强制自动播放。
- 拖动时间轴或单步切换时暂停播放，最后一个月停止。
- 修改任一月度销售、采购、采购价或负荷、切换合同、切换场景或离开沙盘时，停止播放并释放本场景图表。
- 修改参数后上一次当前结果立即失效，需要再次点击运行；历史比较快照不随之改变。
- 切换合同初始化该合同的基线销售、BOM 采购量、采购价格和负荷；“恢复合同基线节奏”仅恢复当前合同。
- 取消运行后不发布结果；防止旧运行在取消或场景切换后回写页面。

### 8.4 月度解释规则

解释内容由同一份结果数据生成，包括当月采购价、用户设定产能负荷、单位加工成本、系统计划生产量、预计单位生产成本、期末原料与成品库存、放弃销量和累计利润。采购先入库并形成原料移动加权价；系统按履约需求与累计可用原料计算计划生产量；实际履约按成品移动加权成本结转销售成本。

当月可履约量等于计划销售量、可用成品量两者的较小值。计划销售未能当月履约的部分计为放弃销量，不自动顺延；因此采购量不需要逐月满足销售，但采购总量仍必须等于 BOM 折算总需求。

### 8.5 情景比较与导出

- 成本场景最多保留三个可比结果，只比较同一合同、同一快照、相同时域、相同基线与模型版本的不同月度节奏。
- 成本结果与原三个库存/交付场景分组保存，不放进同一张指标表。
- 比较列标题显示履约率、放弃销量和利润摘要；展示实际履约量、放弃销量、销售收入、销售成本、合同利润和经营状态。
- 切换合同后只显示当前合同对应的比较组；不会将另一份合同套用当前基线。
- 加入比较时深拷贝结果及基线，不能只保存对可变对象的引用。
- 导出沿用现有 TXT 报告形式，包含合同、快照、BOM 总需求、五项结果、月度计划与实际明细、期末库存、模型版本和计算前提。
- 报告必须由保存的结果快照生成，不重新读取当前控件或已变动的合同配置。
- 比较结果仅在当前浏览器页面会话中保存；不宣传为数据库持久化结果库。

## 12. 校验与验收

### 12.1 计算验收

| 用例 | 预期 |
|---|---|
| 合同基线节奏 | 月度销售合计等于合同总量、月度采购合计等于 BOM 总需求；全量履约，期末原料与成品为零 |
| 销售节奏调整 | 只要各月销售加总不变即可运行；合计不等于合同总量时阻断 |
| 采购节奏调整 | 只要各月采购加总等于 BOM 总需求即可运行；不要求当月采购满足当月销售 |
| 采购价格调整 | 只改变对应月份采购入库金额，并通过原料移动加权价传导至生产成本、销售成本和利润 |
| 生产量计算 | 当月累计可用原料足够时，计划生产量等于履约销量；不足时，等于累计可用原料除以 BOM 耗用系数 |
| 生产负荷调整 | 只改变单位加工成本和预计单位生产成本；相同销售、采购条件下不改变系统计划生产量、原料移动加权价、BOM 耗用系数或预计单位原料成本 |
| 单位原料成本 | 等于原料移动加权价（元/吨原料）乘 BOM 耗用系数（吨原料/吨成品）；结果单位为元/吨成品，不受负荷影响 |
| 单位生产成本 | 等于预计单位原料成本加单位加工成本；不叠加其他单位成本 |
| 销售早于采购 | 当月累计可用原料不足部分计为放弃销量且不自动顺延；后续允许形成原料库存 |
| 期末剩余原料 | 采购金额与已耗用原料成本的差额作为期末库存资产结转，不计入本合同销售成本和利润 |
| 零销售月份 | 当月实际履约、收入和销售成本为零，已有库存可继续保留 |
| 第二份十二个月合同 | 按该合同自己的 BOM、产能、价格和月度基线计算，不能复用 F55 参数 |
| 重复运行 | 除运行 ID、时间和审计时间外，数值和结论一致 |
| 汇总勾稽 | 月度收入、销售成本和利润分别等于期间汇总；收入减成本等于利润，库存数量与金额前后连续 |

### 12.2 数据与异常验收

- 校验合同 ID、日期、月度月份唯一性、月度数量非负、采购价格为正数、产能负荷为 50%～100% 整数、有限数值和完整成本档位。

- 原料耗用系数、采购价格和月产能应为有效正值；缺失数据不得默认替换为零。
- 明确填零的无交付月份与缺失月度数据不同；缺失月份提示数据不完整，不静默当作零。
- 合同已结束、没有下月及以后计划、合同总量为零时不生成利润结论。

### 14.10 单位原料成本独立展示与麦芽糖售价修正

2026-10-12：模型版本升级为 `COST-SIM-V9`，数据版本升级为 `COST-DEMO-V5`。生产区、月度结果、月份故事和导出报告将成本拆分为三个可直接勾稽的字段：

- `预计单位原料成本 = 原料移动加权价（元/吨原料）× 固定 BOM 耗用系数（吨原料/吨成品）`；相乘的目的是计量单位换算，与产能负荷无关。

F55 首月原料移动加权价为 3,000 元/吨原料，固定 BOM 为 0.8000 吨原料/吨成品，因此单位原料成本固定为 2,400 元/吨成品。将首月负荷从 80% 降至 50% 后，单位原料成本仍为 2,400 元/吨，单位加工成本由 338.67 元/吨升至 440.00 元/吨，预计单位生产成本由 2,738.67 元/吨升至 2,840.00 元/吨，证明负荷未改变原料成本。
