# SCOS 业务蓝图

本仓库用于管理 SCOS（全局供应链优化与协同系统）的业务蓝图及相关资料。

## 目录说明

- `0-raw-原始会议资料`：原始会议纪要、问答等材料
- `1-wiki-资料沉淀`：项目过程中整理的通用资料
- `2-业务蓝图-draft`：蓝图草稿
- `3-业务蓝图-终态`：定稿版蓝图
- `业务蓝图-案例`：已有项目案例
- `参考资料`：架构、业务、工艺及需求参考文件

## 文件格式

`0-raw-原始会议资料`、`1-wiki-资料沉淀` 和 `2-业务蓝图-draft` 中的文档统一使用 Markdown（`.md`）格式，不限定具体命名方式。

> 请按目录分类维护文件，定稿前保留清晰的版本记录。
