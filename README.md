# SCOS 业务蓝图

本仓库用于管理 SCOS（全局供应链优化与协同系统）的业务蓝图及相关资料。

## 目录说明

- `0-raw-原始会议资料`：原始会议纪要、问答等材料
- `1-wiki-资料沉淀`：项目过程中整理的通用资料
- `2-业务蓝图-draft`：蓝图草稿
- `3-业务蓝图-终态`：定稿版蓝图
- `utils`：蓝图文档生成、组装等工具脚本
- `业务蓝图-案例`：已有项目案例
- `参考资料`：架构、业务、工艺及需求参考文件

## 文件格式

- `0-raw-原始会议资料`：使用 `.md` 或 `.txt` 格式，文件名以 `YYYYMMDD` 日期开头，例如 `20260819-会议纪要.md`。
- `1-wiki-资料沉淀`：文档优先使用 Markdown（`.md`）格式，不限定具体命名方式。
- `2-业务蓝图-draft`：主体文档优先使用 Markdown（`.md`）格式，可保留图片、流程图、演示页和阶段性 Word 文档等配套文件。
- 工具脚本统一放在 `utils` 目录下。

## 提交规则

1. 提交前先同步远程 `main` 分支，并检查待提交的文件清单。
2. 一次 commit 尽量聚焦于同一批次或同一主题的文档变更。
3. commit message 使用 `<type>: <简要说明>` 格式，常用类型包括 `docs`、`chore` 和 `fix`。
4. 每次提交时同步更新下方“提交记录”，日期标题格式为 `---YYYY.M.D---`。
5. 不提交 `.DS_Store`、Office 临时文件及已列入 `.gitignore` 的本地大文件或演示资源。
