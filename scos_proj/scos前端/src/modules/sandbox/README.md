# 沙盘推演

驾驶舱页头、侧栏和预警详情可进入 `/sandbox`。场景使用只读基线，运行只保存模拟参数和结果。

- `pages/` 和 `components/` 负责参数表单、差量对比、播放、诊断和评估交互。
- `model/` 管理可重现的输入、快照版本、运行状态及可比性。
- `domain/` 实现原型的逐日库存及合同期成本计算，供 Mock 适配器调用。
- `mocks/` 从要货、执行、成品库存样例组成基线，补入 DEMO v3.2 合同模型配置。快照 ID 随样例内容变化，历史方案和评估任务保存于当前浏览器。
- `api/` 区分 Mock 与 HTTP。计划中的 HTTP 契约为 `/v1/sandbox` 下的 `baselines`、`runs`、`scenarios`、`history` 和 `evaluations`。运行由服务端返回任务标识及状态，前端轮询运行结果。路径和状态需以后端联调为准。

蓝图参照业务蓝图 3.2.1、4.2、5.2.1，技术蓝图 3.1.3.6–3.1.3.7、3.1.5.4。原型提供需求、到货、产能和合同成本四个场景。库存策略在「库存优化」页按产品试算，已保存的旧沙盘结果可查阅。沙盘支持 7/14 天或合同期结果、同口径对比、版本保存、报告导出及评估受理和反馈。模拟里的“未评估”需要相应的排程、采购、库存或成本服务结果。评估任务引用原运行和假设，正式调整由各业务模块在新的正式快照上评估、审批、发布。
