# 成品库存优化

维护成品库存策略，协同月、周、日补充计划。

- `pages/`：库存优化、补货计划明细和库存健康度。库存策略在库存预测上方调整，补货计划明细可在月、周、日之间切换。
- `components/`：本模块专用组件。
- `api/`：接口契约、HTTP 适配器和 DTO 映射。
- `model/`：类型、模块定义、Pinia 状态及用例编排。
- `domain/`：不依赖 Vue/DOM/HTTP 的展示推导、输入校验；正式计算结果来自后端。
- `mocks/`：实现相同接口契约的本地样例，禁止在页面硬编码数据。
- `routes.ts`：本模块路由，按模块懒加载。
- `index.ts`：唯一公共导出入口。

演示快照沿用库存 DEMO 的 SKU、出货计划、订单、库存与储罐数据。确认库存策略后保存参数版本，库存预测和补货计划使用当前生效的版本。可以选择历史版本并确认切回。月度补充额度经确认后用于四周补充计划。首周及滚动锁定范围保持只读，模拟生产确认的批次按预计可销售日期计入日度库存。异常和复盘可将调整原因带回策略编辑区，演示记录保存在浏览器中。

库存优化页用同一预测期展示出货需求、库存风险、日度曲线和周汇总。日历默认收起，展开后从预测起始日显示四周，可在默认两个月或自行选择的区间里按四周翻阅。确认策略后更新预计可用库存、生产补充需求和预计产出，超出数据范围的日期显示「暂无预测」。

库存健康度按成品和已结束月份对照原计划与实际执行，自动汇总日度偏差、库存预警、策略建议和跟进事项。月度计划提供历史执行汇总和完整复盘入口。复盘使用对应期间的计划和策略版本，实绩缺失时标记覆盖情况。

补货计划明细中的计划出货、车间产量、入库量和期末可用库存分别按计划出货日、车间完工日、仓库入库日和成品可用日展示。演示数据单独记录车间交接和仓库入库时点，用于识别在途批次。
