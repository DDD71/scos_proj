# 成本核算分析

从批次谱系归集成本，追踪订单盈利与经营影响。

- `pages/`：共享快照的成本工作区及谱系、批次成本、订单盈利、管理决策四个业务页面。
- `components/`：本模块专用组件。
- `api/`：接口契约、HTTP 适配器和 DTO 映射。
- `model/`：类型、模块定义、Pinia 状态及用例编排。
- `domain/`：不依赖 Vue/DOM/HTTP 的展示推导、输入校验；正式计算结果来自后端。
- `mocks/`：实现相同接口契约的本地样例，禁止在页面硬编码数据。
- `routes.ts`：本模块路由，按模块懒加载。
- `index.ts`：唯一公共导出入口。

原型使用 2026 年 8 月太仓工厂的 DEMO 数据。谱系、成本、费用池、订单和规则来自
`4-业务蓝图-DEMO/demo/assets/data/costing/`，原型保留供查询和下钻的字段。
财务对比采用管理决策 DEMO 的样例，F55 标准成本为独立标记的 Mock 值。
正式查询接口、审批、月度任务执行和成本计算待后端联调。
