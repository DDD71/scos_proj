# 采购优化

根据物料需求和供应条件确定供应商及采购量。

- `pages/`：采购方案、供应商资料、执行情况及模块导航。
- `components/`：本模块专用组件。
- `api/`：接口契约、HTTP 适配器和 DTO 映射。
- `model/`：字段类型、模块定义和本地草稿。
- `domain/`：不依赖 Vue/DOM/HTTP 的展示推导、输入校验；正式计算结果来自后端。
- `mocks/`：实现相同接口契约的本地样例，禁止在页面硬编码数据。
- `routes.ts`：本模块路由，按模块懒加载。
- `index.ts`：唯一公共导出入口。

首页需求缺口与新建方案使用同一已发布需求版本的净算结果。新建时可在缺口基础上增加预期采购量。采购方案工作台在同页展示候选供应商、求解参数和建议采购方案。业务人员可禁用候选供应商，设置最少供应商家数、最高和最低采购占比，以及年化资金成本率。采购占比按预期采购量计算。首页销售订单 BOM 统计用于参考。

工厂、物料、供应商、报价和订单执行字段参考《SCOS全量接口清单v2》。HTTP 路径集中在 `api/procurement.repository.ts`，其中已发布原材料需求的来源及读取接口仍待联调。Mock 模式沿用旧 DEMO 的需求版本，分期供应分配为演示假设。

草稿保存在当前标签页的会话存储中，刷新可继续编辑。Mock 模式按演示报价和供应能力分配采购量。正式求解、审批、发布及上游接口联调仍待接入。
