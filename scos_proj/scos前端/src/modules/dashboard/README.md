# 供应链驾驶舱

统一查看销售、库存、生产、采购与经营态势。

- `pages/`：组合指标总览、地图、预警和专题分析。
- `components/`：本模块专用组件。
- `api/`：接口契约、HTTP 适配器和 DTO 映射。
- `model/`：类型、模块定义、Pinia 状态及用例编排。
- `mocks/`：实现相同接口契约的本地样例，禁止在页面硬编码数据。
- `routes.ts`：本模块路由，按模块懒加载。
- `index.ts`：唯一公共导出入口。

在示例模式下，库存预警和到货偏差从对应模块的演示快照生成，按物料或执行单据下钻。销售、生产与经营使用同期演示数据。统计期间切换只影响指标与专题，地图和待处置预警显示最新加载的供应链快照。

正式指标数据由后端按快照和口径提供。前端通过驾驶舱仓储接口读取，示例数据放在 mock 适配器中。
