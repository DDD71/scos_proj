# 原辅包要货计划

在有效合同范围内，协调每天的原辅包到货安排。

- `pages/`：要货概览、周要货计划和已签约供应商。周计划从概览进入，周内按日展示与计算。
- `components/`：本模块专用组件。
- `api/`：接口契约、HTTP 适配器和 DTO 映射。
- `model/`：类型、模块定义及周计划草稿。
- `domain/`：不依赖 Vue/DOM/HTTP 的逐日库存投影及输入校验。
- `mocks/`：实现相同接口契约的本地样例，禁止在页面硬编码数据。
- `routes.ts`：本模块路由，按模块懒加载。
- `index.ts`：唯一公共导出入口。

当前以本地数据演示周要货计划、已签约供应商和计划下达与执行。供应商页按合同展示供货总量和可安排余量。执行页使用预置已发布计划演示下达、单行重试和履约反馈。正式计算、业务接口和审批待接入。

概览按接口清单 v2 对照 SAP 物料主数据（#1）、采购订单（#70）、WMS 库存查询（#124）和 TMS 每日到货（#226）。原辅包库存以 WMS 快照的可用数量和库存时点为输入。逐日期末可用量为期初可用量加到货量减生产耗用，负值的绝对值为累计生产缺口。到货明细分开展示原计划日期及最新预计到厂时间，订单号和行号用于联调关联，缺字段时显示短横线。日度生产耗用使用计划快照，包材样例注明 BOM 换算来源。演示按预计到厂当天可用计算，正式口径以 WMS 可用量及质检放行为准。

周计划先展示本周需求缺口、候选供应商的供货条件，以及所选物料在 WMS 快照中的仓库上限，再展示生成的供应商要货计划。每日入库峰值以 WMS 在库量推演，计入当天已有到货和建议到货后，再扣生产耗用。在库量中的待检和冻结库存仍占仓，应与用于保障投料的可用数量区分。演示按当天到货在投料前入库且可用计算。草稿继续编辑时使用当前快照的上限，已确认计划保留确认时使用的上限。求解在合同、供应、收货和仓容限制内优先补生产缺口，并尽量合并同一供应商的批次。
