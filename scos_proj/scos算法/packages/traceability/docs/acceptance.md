# 全程追溯与质量协同验收清单

这是包内分项清单，暂不规定验收先后。批次、数据集、容差、性能指标和签收人需要立项时明确；没有基准数据及通过证据的项目不能判定通过。

| 编号 | 验收项 | 基准输入与预期结果 | 状态 |
| --- | --- | --- | --- |
| TRACEABILITY-01 | 原料到客户的正向追溯与反向追溯 | 待准备 | 未实现 / 未验收 |
| TRACEABILITY-02 | 跨系统批次关系、拆分合并与断链提示 | 待准备 | 未实现 / 未验收 |
| TRACEABILITY-03 | 质量事件影响库存、成品、订单和客户的范围计算 | 待准备 | 未实现 / 未验收 |
| TRACEABILITY-04 | 隔离召回放行的建议依据与可追溯路径 | 待准备 | 未实现 / 未验收 |

每项都要关联业务蓝图条目、输入快照、参数/模型/契约版本、预期结果及容差、实际输出、报告和签收记录。正常、边界、缺失输入及异常场景分别记录。耗时必须注明硬件、数据规模和求解限制。

包级验收分为计算验收和服务集成验收：计算可离线执行，使用经业务确认的固定样本；服务验收覆盖 Java 调用、幂等、版本兼容、权限、任务生命周期和失败恢复。两者结果分别记录，不能用页面显示成功替代计算正确性。

交付条件按 [统一验收规则](../../../docs/acceptance-policy.md) 执行。当前所有项均未实现、未验收。
