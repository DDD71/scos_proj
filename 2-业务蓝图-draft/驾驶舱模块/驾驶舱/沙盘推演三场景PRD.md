# SCOS 沙盘推演三场景 PRD

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品 | SCOS 供应链驾驶舱沙盘推演 |
| 版本 | V1.0 |
| 日期 | 2026-09-09 |
| 阶段 | 静态 DEMO 与业务评审 |
| 数据口径 | Mock 数据，仅用于演示交互与计算逻辑 |

## 2. 产品定位

沙盘推演用于回答一个问题：当某个关键业务条件发生变化时，供应链会在什么时间、哪些对象上出现什么影响。

首期只建设三个高频场景：

1. 客户增单与交期变化；
2. 供应商到货延迟；
3. 生产能力下降。

每个场景只开放两个可调变量。客户、产品、供应商、物料和产线用于确定计算范围，不视为情景变量。

沙盘只提供分析和决策参考，不修改正式订单、采购计划、生产排程和库存策略，不生成采购订单、生产工单或审批任务。

## 3. 产品目标

- 用户在 1 分钟内完成一次情景设置和运行；
- 用户不需要理解模型细节即可看懂关键影响；
- 结果必须明确给出风险发生日期和受影响对象；
- 相同基线、参数和模型版本能够得到相同结果；
- 所有模拟结果与正式业务数据隔离。

## 4. 范围与非范围

### 4.1 本期范围

- 三个预置场景；
- 同源基线快照展示，支持切换未来 7 天或未来 14 天；
- 每个场景两个变量调整；
- Mock 模拟运行进度；
- 基线与模拟结果对比；
- 库存水位和安全库存线；
- 风险日期、影响链和受影响对象；
- 情景横向比较；
- 模拟报告导出。

### 4.2 本期不做

- 多风险组合压力测试；
- 用户自定义计算脚本；
- 自动推荐并采纳处置方案；
- 将模拟结果带入采购、库存或排程审批；
- 生成采购订单、生产工单或正式库存策略；
- 修改质量、工艺、安全和环保硬约束。

## 5. 统一业务流程

```text
选择场景
  → 选择业务对象
  → 查看基线快照
  → 选择未来 7 天或未来 14 天
  → 调整两个变量
  → 运行模拟
  → 拖动或播放时间轴，逐日查看生产、到货、库存和交付变化
  → 查看风险日期和受影响对象
  → 查看基线与模拟指标
  → 加入情景比较或导出报告
```

### 5.1 页面初始状态

- 默认选择“客户增单与交期变化”；
- 默认加载 `SNAP-20260823-0900` 快照；
- 显示数据截止时间、组织、时域、计划版本和数据质量；
- 参数使用模板默认值；
- 未运行前不展示模拟结果。

### 5.2 参数变化

- 滑块变化时立即更新参数值；
- 推演时域切换后立即清空上一次结果，并按新的 7 天或 14 天范围重新计算；
- 参数变化后清空上一次结果，避免旧结果与新参数混淆；
- “恢复模板参数”恢复当前场景默认值；
- 业务对象变化后沿用当前场景的两个变量，但重新计算该对象的基线。

### 5.3 运行状态

运行过程依次显示快照校验、模型调用和结果聚合。允许取消；取消后显示“结果不完整”，不输出全局结论。

## 6. 场景一 客户增单与交期变化

### 6.1 用户故事

作为供应链总监或调度员，我希望模拟某客户订单增加和交期提前后的影响，以便提前识别产能、库存、采购和交付风险。

### 6.2 业务对象

| 对象 | 示例 |
|---|---|
| 客户 | 客户 C012、统一集团、康师傅、娃哈哈 |
| 成品 | 果葡糖浆 F55、果葡糖浆 F42、麦芽糊精、结晶葡萄糖 |

### 6.3 可调变量

| 变量 | 范围 | 步长 | 默认值 |
|---|---:|---:|---:|
| 订单数量变化 | -30%～+50% | 5% | +20% |
| 要求交付提前 | 0～7 天 | 1 天 | 2 天 |

### 6.4 Mock 计算逻辑

```text
模拟日需求 = 基线日需求 ×（1 + 订单变化率）
提前交付量 = 基线日需求 × 提前天数 × 0.35
每日库存 = 上日库存 + 当日计划入库 - 模拟日需求 - 当日提前交付量
产线负荷率 = min（100%，82% + 订单变化率×0.7 + 提前天数×2）
```

原料模拟需求随订单变化按比例调整。采购缺口只作为模拟输出，标记“未发布”。

### 6.5 模型传导

```text
订单变化
→ 生产排程评估产能与完工日
→ 成品库存计算逐日水位
→ 原料需求计算增量
→ 采购评估原料缺口
→ 成本服务汇总影响
```

### 6.6 输出

- 模拟日均出库；
- 关键产线负荷；
- 跌破安全库存日期；
- 预计缺货日期；
- 原材料模拟需求缺口；
- 受影响客户订单；
- OTD 和供应链总运营成本变化。

### 6.7 默认演示案例

客户 C012 的果葡糖浆 F55 订单增加 20%，要求交付提前 2 天。系统展示 3#异构化线负荷、F55 每日库存水位、预计缺货日和受影响订单。

## 7. 场景二 供应商到货延迟

### 7.1 用户故事

作为采购或供应链管理人员，我希望模拟关键供应商延期和可供量下降后的影响，以便判断何时缺料、哪些生产计划和客户订单会受到影响。

### 7.2 业务对象

| 对象 | 示例 |
|---|---|
| 供应商 | 德州金玉米、吉林长龙生化、齐齐哈尔龙凤、诺维信中国 |
| 原材料 | 玉米淀粉、液化酶、糖化酶、活性炭 |

### 7.3 可调变量

| 变量 | 范围 | 步长 | 默认值 |
|---|---:|---:|---:|
| 到货延迟天数 | 0～14 天 | 1 天 | 7 天 |
| 可供量下降 | 0%～100% | 10% | 50% |

### 7.4 Mock 计算逻辑

```text
模拟到货日 = 原计划到货日 + 延迟天数
模拟到货量 = 原计划到货量 ×（1 - 可供量下降比例）
每日原料库存 = 上日库存 + 当日模拟到货 - 当日生产消耗
```

原料库存首次低于安全库存的日期为越线日，首次小于等于零的日期为预计缺料日。预计缺料后关联对应产线计划和客户订单。

### 7.5 模型传导

```text
供应商延期和减量
→ 采购模型重算可供量
→ 原料到货约束传给生产排程
→ 完工变化传给成品库存
→ 评估客户交付和替代采购成本
```

### 7.6 输出

- 原计划与模拟到货日期；
- 原料跌破安全库存日期；
- 预计缺料日期；
- 受影响生产计划和数量；
- 受影响客户订单；
- OTD、原料缺口和替代采购成本变化。

### 7.7 默认演示案例

德州金玉米的玉米淀粉延迟 7 天、可供量下降 50%。系统展示玉米淀粉水位、2#糖化线受限计划以及客户订单延期风险。

## 8. 场景三 生产能力下降

### 8.1 用户故事

作为生产调度员或供应链总监，我希望模拟某产线在一段时间内产能下降后的影响，以便判断生产缺口、库存能够支撑到哪一天以及哪些订单可能延期。

### 8.2 业务对象

| 对象 | 对应成品示例 |
|---|---|
| 1#液化线 | 结晶葡萄糖 |
| 2#糖化线 | 果葡糖浆 F42 |
| 3#异构化线 | 果葡糖浆 F55 |
| 4#喷雾干燥线 | 麦芽糊精 |

### 8.3 可调变量

| 变量 | 范围 | 步长 | 默认值 |
|---|---:|---:|---:|
| 产能下降比例 | 0%～60% | 5% | 30% |
| 影响持续时间 | 0～5 天 | 1 天 | 2 天 |

### 8.4 Mock 计算逻辑

```text
计划产量缺口 = 基线计划入库量 × 产能下降比例 × 持续天数 ÷ 2
模拟有效产出 = 基线计划入库量 - 计划产量缺口
模拟入库延迟 = ceil（持续天数 × 产能下降比例）
每日成品库存 = 上日库存 + 模拟计划入库 - 当日需求
```

当产能下降比例或持续时间任一为零时，本次场景视为无有效扰动，结果与基线一致。

### 8.5 模型传导

```text
产能下降
→ 排程重算有效产出和完工日期
→ 成品库存重算计划入库和每日水位
→ 识别订单延期
→ 成本服务汇总恢复生产和延期成本
```

### 8.6 输出

- 有效产能；
- 计划产量缺口；
- 模拟入库日期和数量；
- 跌破安全库存日期；
- 预计缺货日期；
- 受影响订单数量；
- OTD、产线负荷和成本变化。

### 8.7 默认演示案例

3#异构化线产能下降 30%，持续 2 天。系统展示 F55 计划入库减少量、库存越线日、缺货日和受影响客户订单。

## 9. 统一结果页

结果页按固定顺序展示：

1. 四个场景关键结果；
2. 生产或到货变化与库存水位联动图，两层图表共享同一时间轴；
3. 可拖动、可播放的逐日时间轴，并展示所选日期的生产/到货、库存、安全线差值和业务影响；
4. 关键事件时间线；
5. 受影响对象明细；
6. 基线与模拟核心指标表；
7. 跨模块影响链；
8. 模拟范围和安全边界说明。

### 9.1 关键日期定义

```text
安全库存越线日 = 第一个库存水位 < 安全库存的日期
预计缺货日 = 第一个库存水位 ≤ 0 的日期
```

如果展望期内未发生，显示“时域内未发生”，不得强行给出日期。

### 9.2 核心指标

| 指标 | 展示方式 |
|---|---|
| 订单准时交付率 | 基线、模拟、变化百分点 |
| 关键产线负荷率 | 基线、模拟、变化百分点 |
| 推演期最低成品库存 | 基线、模拟、变化吨数 |
| 模拟原材料需求缺口 | 基线、模拟、变化吨数 |
| 供应链总运营成本 | 基线、模拟、变化金额 |

## 10. 校验与异常

- 业务对象无效、快照未就绪或必需数据缺失时禁止运行；
- 百分比、天数和数量不得超出配置范围；
- 参数变化后旧结果立即失效；
- 运行取消后不显示缺货日或全局结论；
- 模型部分失败时显示“部分成功”和未评估范围；
- 零冲击参数必须得到与基线一致的结果；
- 不允许自动放宽质量、工艺、安全和环保硬约束。

## 11. 权限与审计

- 按组织和角色控制可选客户、供应商、物料、产品和产线；
- 记录创建人、运行人、快照、参数差量、运行时间和导出操作；
- 页面和报告持续显示“模拟结果，仅供分析，不下发生产”；
- 沙盘服务账号对 SAP、E采、MES 和正式库存策略库只读。

## 12. 验收标准

### 12.1 通用验收

- 左侧只显示三个场景；
- 每个场景只有两个滑块变量；
- 修改任一变量后结果产生可解释变化；
- 支持未来 7 天和未来 14 天切换，结果日期范围与所选时域一致；
- 支持拖动时间轴、点击图表日期和自动播放，逐日信息与曲线同一天联动；
- 结果包含具体日期、对象和数量；
- 支持恢复默认参数、取消运行、加入比较和导出；
- 模拟全过程不修改正式数据。

### 12.2 场景验收

- 增加订单量或提前交期后，产线负荷、库存消耗和交付风险按方向变化；
- 增加供应延迟或降低可供量后，原料越线日和缺料日不得变晚；
- 提高产能下降比例或延长持续时间后，计划产量缺口不得减少；
- 所有变量回到零冲击时，模拟结果与基线一致；
- 同一快照和同一参数重复运行结果一致。

## 13. 后续扩展

价格波动、库存策略、质量冻结、物流中断和组合压力测试暂不进入首期页面。完成三类核心场景业务验收后，再根据实际数据和模型接口逐项扩展。
