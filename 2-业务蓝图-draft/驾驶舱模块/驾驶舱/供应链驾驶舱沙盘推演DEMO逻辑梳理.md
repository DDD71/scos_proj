# 供应链驾驶舱沙盘推演 DEMO 逻辑梳理

> 用途：梳理沙盘演示思路和各场景计算逻辑，便于产品、业务和研发统一理解。  
> 说明：文中的日期、数量和金额为静态 DEMO 演示口径，正式系统应以指定数据快照和各业务模型的实际结果为准。

## 1. 沙盘定位

沙盘用于回答三个问题：

1. 如果某个业务条件发生变化，会从哪里开始传导？
2. 哪一天会越过安全线或发生缺货，会影响哪些计划和订单？
3. 叠加某项应对假设后，风险和成本会如何变化？

沙盘只提供认知和决策参考：

- 不修改正式订单、排程、库存策略和采购计划；
- 不生成采购订单、生产工单或审批任务；
- “应对假设”只用于再次模拟和方案比较，不代表系统推荐或业务采纳；
- 如需实际处理，业务人员应退出沙盘，进入采购、库存或排程模块按正式流程操作。

若其他旧稿仍存在“方案采纳、下发正式方案”等描述，以本边界及《驾驶舱模块技术方案》当前版本为准。

## 2. 统一推演逻辑

~~~text
锁定同源数据快照
  → 叠加用户假设参数
  → 校验对象、单位、时域和权限
  → 按依赖顺序调用采购/排程/成品库存/成本模拟接口
  → 计算库存水位、缺口、交期、产能和成本
  → 展示基线 vs 风险暴露 vs 应对假设
  → 保存或导出带“模拟”标识的报告
~~~

核心日期口径：

- 每日库存水位 = 上日库存 + 当日计划入库 - 当日需求/消耗；
- 安全库存越线日 = 第一个“库存水位 < 安全库存”的日期；
- 预计缺货日 = 第一个“库存水位 ≤ 0”的日期；
- 原材料库存和成品库存分别计算，不混用；
- 任一关键模型失败或数据缺失时，结果标记为不完整，不输出全局结论。

结果页统一展示：关键日期、库存/成本曲线、受影响对象、跨模块影响链、核心 KPI 变化、模型完整性和模拟水印。

## 3. 当前 DEMO 场景总览

| 场景 | 主要业务问题 | 默认演示案例 | 主要调用模块 |
|---|---|---|---|
| 需求波动 | 客户临时增单或交期提前后能否按期交付 | F55 订单增加 20%，交期提前 2 天 | 排程 → 成品库存 → 原料需求/采购 → 成本 |
| 供应风险 | 供应商延期后哪一天缺料、影响哪些订单 | 德州金玉米延期 7 天，可供量下降 50% | 采购 → 排程 → 成品库存 → 成本 |
| 生产扰动 | 设备停机和紧急插单会造成什么后果 | 3#异构化线停机 8 小时，插单 500 吨 | 排程 → 成品库存 → 采购评估 → 成本 |
| 成品库存策略 | 补充周期或库容变化后何时缺货 | 麦芽糊精服务水平 98%，补充周期 5 天，停用 2 座储罐 | 成品库存 → 成本 |
| 成本/价格波动 | 原料和运费上涨对采购 TCO 的影响 | 玉米淀粉价格 +15%，运费 +8% | 采购 → 成本 |
| 组合压力测试 | 多个风险同时发生时最坏结果是什么 | 需求、供应、设备和价格同时承压 | 按依赖关系调用全部相关模块 |

## 4. 各场景 DEMO 逻辑

### 4.1 需求波动：大客户临时增单

**业务案例**：客户 C012 的果葡糖浆 F55 订单增加 20%，并要求提前 2 天交付。

**推演逻辑**：

1. 将订单增量和新交期传入排程模型，重新计算 3#异构化线负荷和完工时间；
2. 将模拟出库需求、模拟计划入库传入成品库存模型，逐日计算 F55 库存；
3. 根据模拟排程计算原材料需求；具备模拟原料需求能力时再调用采购模型；
4. 汇总加班、采购、库存和延期成本。

**当前示例结果**：关键产线负荷达到 100%，08-30 跌破安全库存，08-31 预计缺货；页面显示受影响客户、订单、排程和原料需求。订单下降时，逻辑反向表现为产能释放、库存消耗放缓和采购增量减少。

**二次比较**：模拟提前生产和增加一次补产，比较缺货日和延期订单数是否改善；不自动调整正式排程。

### 4.2 供应风险：主力供应商延期

**业务案例**：德州金玉米的玉米淀粉原计划 08-26 到货，模拟延期 7 天且可供量下降 50%。

**推演逻辑**：

1. 将受影响周期的供应商可供量调低，并把剩余到货移到延期后的日期；
2. 采购模型重新计算供应商分配和剩余缺口；
3. 将模拟到货数量和日期作为排程的原料可用约束；
4. 排程完工变化继续传导至成品库存和客户交付；
5. 评估备用采购和加急运输成本。

**当前示例结果**：模拟到货日变为 09-02；玉米淀粉 08-28 跌破安全库存，08-30 预计缺料，约 3,416 吨生产计划及 2 个客户订单受到影响。

**二次比较**：模拟吉林长龙补量、齐齐哈尔加急后，比较是否仍会缺料、OTD 是否恢复以及额外成本；不生成采购订单。

### 4.3 生产扰动：停机叠加紧急插单

**业务案例**：3#异构化线计划外停机 8 小时，同时插入 500 吨紧急订单。

**推演逻辑**：

1. 冻结停机窗口，重新计算可用产能、工序衔接和订单顺序；
2. 紧急订单占用剩余产能，普通订单相应后移；
3. 将新的完工与计划入库日期传入成品库存模型；
4. 根据排程变化检查原料到货时点性缺口；
5. 汇总切换、加班和交付延期成本。

**当前示例结果**：F55 原计划 08-26 入库，模拟后移至 08-27；08-29 跌破安全库存，08-31 预计缺货，至少 2 个订单进入延期窗口。

**二次比较**：模拟跨线转产 450 吨并增加加班产出，比较缺货日和延期订单数；不生成 MES 工单。

### 4.4 成品库存策略：补充变慢且库容下降

**业务案例**：麦芽糊精目标服务水平设为 98%，生产补充周期为 5 天，并模拟停用 2 座储罐。

**推演逻辑**：

1. 按服务水平和需求波动重算模拟安全库存；
2. 按补充周期确定计划入库日；
3. 按可用储罐容量限制模拟入库量和目标库存；
4. 逐日计算未来库存水位、越线日和缺货日；
5. 评估服务水平变化和库存资金占用。

**当前示例结果**：模拟安全库存为 372 吨，08-24 低于安全线，09-02 预计缺货；正式库存策略保持不变。

**二次比较**：模拟提前 1 天补产并恢复部分库容，比较缺货是否避免及资金占用变化。

### 4.5 成本/价格波动：原料价格上涨

**业务案例**：玉米淀粉价格上涨 15%，运输费用上涨 8%，年化资金成本率为 4.2%。

**推演逻辑**：

1. 重估框架合同、浮动价和现货采购的综合成本；
2. 采购模型在可供量、合同量和账期约束下重新分配供应商份额；
3. 成本服务统一折算价格、运费和资金成本；
4. 若新的采购组合改变到货量或到货期，再联动排程和库存；否则不扩大调用范围。

**当前示例结果**：W39 模拟采购 TCO 为 3,137.6 万元；提高固定价比例并分批询价的模拟结果可节省约 174.5 万元。

**二次比较**：比较“维持原结构”和“锁价 + 分批询价”两条成本曲线；不形成合同或询价单。

### 4.6 组合压力测试：多风险同时发生

**业务案例**：需求增加、供应延期、原料涨价和设备停机同时发生。

**推演逻辑**：

1. 根据输入参数生成模型依赖图，先计算供应和排程约束；
2. 将新的产出、到货和需求结果传给库存模型；
3. 聚合采购、生产、库存、交付和成本结果；
4. 找出最先触发的硬约束、最坏指标和完整风险传导链；
5. 禁止把不同运行版本的中间结果混用。

**当前示例结果**：F55 于 08-27 跌破安全库存，08-30 预计缺货；8 个订单延迟，模拟供应链成本增加 388 万元。

**二次比较**：叠加备用供应商、跨线转产和加班等组合假设，观察剩余风险；各项假设均不自动执行。

## 5. 建议后续增加的实用场景

以下场景适合在数据和模型接口具备后继续扩展，不属于当前静态 DEMO：

| 候选场景 | 典型参数 | 主要影响链 |
|---|---|---|
| 质量批次冻结/召回 | 产品、批次、冻结数量、预计放行时间 | 可用库存下降 → 可发货量下降 → 订单延期；正式质量冻结不可由沙盘解除 |
| 物流线路中断 | 线路、车辆/运力下降、延迟天数、备用仓 | 到货/发货后移 → 仓库或产线水位变化 → 交付风险与加急物流成本 |
| 能源或环保限产 | 蒸汽/电力上限、限产时段、产能下降比例 | 可用产能下降 → 完工后移 → 成品库存下降 → OTD 和单位成本变化 |

## 6. 推荐演示步骤

1. 选择场景并说明业务事件；
2. 展示基线快照、计划版本和数据质量；
3. 调整 2～4 个关键参数并运行模拟；
4. 先讲“哪一天越线/缺货”，再讲受影响计划、订单和成本；
5. 切换“叠加应对假设”，比较风险是否缓解及代价；
6. 加入情景横向对比，说明结果仅供决策参考、不下发生产。

演示时应优先讲清具体对象、具体日期和影响范围，避免只展示综合分数或抽象图表。
