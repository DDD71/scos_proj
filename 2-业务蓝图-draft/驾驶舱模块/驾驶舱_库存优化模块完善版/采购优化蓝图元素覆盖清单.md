# 采购优化蓝图元素覆盖清单

## 1 依据与边界

- 业务节点依据：`SCOS_中粮太仓项目研发模块蓝图方案v1.0.docx` 采购优化四条流程。
- 算法依据：`采购优化模块技术方案.md`。
- 冲突处理：采购优化求解不读取库存和排程、不计算具体供货日期；蓝图中相关旧表述不进入求解工作台，合同、订单和到货状态仅在执行追踪中展示。

## 2 蓝图节点映射

### 2.1 月度采购方案制定

| 蓝图节点 | 系统实现 |
|---|---|
| 10 形成待采购需求 | 新建方案选择已发布需求版本，读取玉米淀粉当期需求并支持人工调整 |
| 20 生成月度采购建议 | 校验候选池及报价后，按技术方案生成最优和次优供应商采购组合 |
| 30 评审并调整采购方案 | 比较推荐方案、查看成本拆解、人工选择方案和调整求解参数 |
| 40 确认采购方案 | 校验需求完全覆盖、供应能力、供应商数、必选供应商和占比约束 |
| 50 审批月度采购方案 | 当前 Demo 用户可提交审批并执行审批通过操作 |
| 60 发布已确认采购方案 | 发布版本并锁定输入快照、参数、方案、意见和审批记录 |
| 70 进入采购执行 | 发布后形成 E采/SAP 执行依据，但不自动创建合同或采购订单 |

### 2.2 供应商评价与准入预警

| 蓝图节点 | 系统实现 |
|---|---|
| 10 提供评价与资质数据 | 资料库汇集供应商主数据、历史质量、交付、价格、资质和风险数据 |
| 准入标准配置 | 采购负责人可维护质量、准时交付、风险分、资质预警天数和允许状态，保存后立即重新判定 |
| 20 生成画像与预警 | 候选池评价页展示画像指标和系统风险提示 |
| 30 判断是否异常 | 按质量、准时率、资质有效期和风险分生成绿黄红状态 |
| 40 复核评价结果 | 用户查看预警依据并填写保留说明或返回候选池调整 |
| 50 判断是否调整状态 | 对限制、暂停、资质临期供应商给出状态处置入口 |
| 60 审批状态调整 | Demo 供应商资料编辑弹窗保留状态调整理由与保存动作 |
| 70 发布评价结果 | 最新评价用于当期候选池和推荐方案同成本排序 |

### 2.3 采购计划滚动调整

| 蓝图节点 | 系统实现 |
|---|---|
| 10 判断未执行安排是否受影响 | 周度检查对比需求、已发布方案、报价、可供量和执行状态 |
| 20 生成滚动调整建议 | 锁定已执行量，仅对受影响的未执行部分重新求解 |
| 30 评审调整建议 | 展示调整前后供应商数量、采购量和成本差异 |
| 40 确认计划调整 | 用户可采纳或拒绝调整并记录说明 |
| 50 发布新版本 | 采纳后发布新版并保留旧版本及计算快照 |
| 60 执行系统接收 | 标记 E采/SAP 待接收新版未执行安排，已执行订单不覆盖 |

### 2.4 采购执行跟踪

| 蓝图节点 | 系统实现 |
|---|---|
| 10 执行采购订单或合同 | 展示 E采/SAP 回传的正式合同和采购订单 |
| 20 发货与在途跟踪 | 展示发货数量、在途状态和预计到货时间 |
| 30 到厂收货与质检 | 展示到货、待检、合格和质量异常状态 |
| 40 更新执行状态 | 汇总合同、订单、发货、到货和质检进度 |
| 50 判断是否需要调整 | 对延期、数量差异和质量异常给出影响判断 |
| 60 发起滚动调整或异常处理 | 可从订单详情或预警进入滚动调整，其他异常转外部流程 |

## 3 技术方案覆盖

| 技术要点 | Demo 实现 |
|---|---|
| 有效报价 | 候选供应商报价有效期和完整性校验 |
| 账期资金成本 | `报价 × 年化资金成本率 × 账期 / 365` |
| 包装袋回收抵扣 | 直接维护元/吨抵扣，缺失按 0 处理 |
| 综合成本目标 | 报价 + 运费 - 账期资金节省 - 包装袋回收抵扣 |
| 采购需求量约束 | 所有供应商分配量之和等于确认需求量 |
| 供应能力约束 | 单家分配不超过本期最大可供量 |
| 最少供应商数 | 参数可维护，求解时硬约束校验 |
| 供应商占比 | 支持入选最低占比和单家最高占比 |
| MILP 决策变量 | 显式建立整数采购量 `x_i` 和二元供应商选择变量 `y_i` |
| MILP 联动约束 | 使用 `x_i` 与 `y_i` 的上下界约束连接供应商选择、MOQ、占比和最大可供量 |
| 启发式求解 | 使用贪心构造产生初始解，并执行供应商 Add、Drop、Swap 邻域搜索 |
| 小规模精确校验 | 候选供应商不超过 18 家时检查全部供应商组合并显示启发式最优性差距 |
| 多方案推荐 | 对启发式与精确校验得到的可行解去重，按综合成本输出最优和次优方案 |
| 同成本排序 | 供应商数量更少优先，再参考质量、准时率和风险分 |
| 价格变化趋势 | 在同一张元/吨价格图中叠加期货价、采购均价及其上月、上年同期价格曲线，不使用变化率 |
