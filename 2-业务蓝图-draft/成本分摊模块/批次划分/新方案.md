# 果葡糖浆批次划分新方案

## 1. 方案概述

### 1.1 建设目标

本方案用于解决果葡糖浆连续生产过程中批次边界难以精确识别、拆批并批关系缺少数量、储罐混料难以追踪、返料回用容易断链等问题，建立一套能够实际运行、可核对、可审计的批次追踪体系。

方案需要同时满足：

1. 支持从供应商原料到客户发货的正向和反向追溯；
2. 支持车辆、糖化罐、QC罐、成品罐和装车等明确物理批次；
3. 支持投料、F42、F90和F55等连续工艺段的逻辑批次追踪；
4. 支持拆批、并批、混罐、返料、回用和过渡料；
5. 支持按实际数量进行质量影响范围计算和批次成本传递；
6. 避免制造无法通过现场数据证明的“绝对精确批界”；
7. 在仪表和自动化条件不足时允许降级运行，并明确数据精度。

### 1.2 核心调整

旧方案以十级批次为主线，试图在每个物流和工艺环节生成新的批次。新方案保留十级结构作为业务展示视图，但不再要求所有层级都以相同方式生成正式批次。

底层模型调整为：

```text
物理批次
+ 原料库存余额
+ 物料转移事件
+ 连续流入口批次
+ 累计量追踪
+ 过渡区贡献比例
+ 数据置信度
```

新方案的核心不是为每一段管道强行切出绝对边界，而是回答：

- 某批物料从哪里来；
- 在什么时间进入和离开工艺段；
- 实际投入、产出和库存是多少；
- 对下游批次贡献了多少；
- 边界是否存在不确定性；
- 质量异常时哪些批次确定受影响、哪些批次可能受影响。

## 2. 设计原则

### 2.1 物理边界优先

存在车辆、独立罐体、阀门切换、完整装车等可靠物理边界时，优先按物理事件划分批次，不使用任意时间窗口替代。

### 2.2 连续流不强求绝对切断

连续生产段采用入口批次、累计流量、有效持液量和过渡范围追踪物料，不假设相邻批次在管道内存在完全清晰的物理切面。

### 2.3 位置移动不等于批次变化

原料从平面库移动到线边时，物料本身未发生生产转化。原则上保持原批次身份，只新增库存位置、数量和移动履历；发生拆分、混合或失去原标识时再生成厂内子批次。

### 2.4 所有关系必须带数量

拆批、并批、混罐、投料、返料和装车必须记录来源、去向、实际数量和时间。只有批次号而没有数量的关系不能用于精确追溯和成本核算。

### 2.5 异常批次不从谱系删除

无效、作废、冻结、不合格和估算批次仍保留在追溯链中。状态只影响是否允许放行、结算和继续使用，不影响历史事实留存。

### 2.6 数据精度透明

系统需要标记批次关系是实际计量、系统计算、比例估算还是人工补录，并给出置信度，避免把估算结果展示为绝对事实。

## 3. 新方案总体模型

### 3.1 四类核心对象

#### 3.1.1 物理批次

具有明确业务或物理边界的正式批次：

- 供应商原料批次；
- 入厂车辆批次；
- 糖化罐批次；
- QC罐批次；
- 成品罐批次；
- 装车/发货批次。

物理批次是质量放行、冻结、召回和正式追溯的主要对象。

#### 3.1.2 连续流逻辑批次

在连续工艺段入口生成，用于跟踪一定时间或累计量范围内进入的物料：

- 投料入口批次；
- F42入口批次；
- F90色谱入口批次；
- F55混合入口批次。

连续流逻辑批次具有入口边界，但下游到达范围通过累计量和过程模型计算，不声明存在绝对出口切面。

#### 3.1.3 批次库存余额

用于记录同一批次在不同位置或容器中的数量：

```text
批次 + 位置/容器 + 数量 + 状态 + 时间
```

典型位置包括：

- 平面库库位；
- 线边工位；
- 在途叉车；
- 糖化罐；
- QC罐；
- 成品罐；
- 装车管道；
- 槽车。

#### 3.1.4 物料转移事件

记录物料在批次、位置、设备和容器之间的实际流动：

| 字段 | 说明 |
| --- | --- |
| 事件类型 | 入厂、卸货、移库、投料、进罐、出罐、分流、混合、返料、装车等 |
| 来源对象 | 来源批次及位置/设备/罐体 |
| 去向对象 | 去向批次及位置/设备/罐体 |
| 数量 | 实际或估算转移量 |
| 开始/结束时间 | 事件发生时间范围 |
| 计量依据 | 地磅、流量计、液位计、袋数、配方、人工确认等 |
| 数据精度 | 实测、计算、估算、补录 |
| 状态 | 待确认、已确认、已修正、已作废 |

### 3.2 业务展示层级

为了保持业务人员熟悉的追溯视图，系统仍可展示以下十级链路：

```text
第1层  供应商原料批次
第2层  入厂原料批次
第2.1  平面库批次库存
第2.2  线边批次库存
第3层  投料逻辑批次
第4层  糖化罐物理批次
第5层  F42连续流批次
第6层  F90连续流批次
第7层  F55混合逻辑批次
第8层  QC罐物理批次
第9层  成品罐物理批次
第10层 装车/发货物理批次
```

其中第2.1和第2.2层主要是同一原料批次的库存分段，并非每次移动都改变原料身份。

## 4. 批次编码方案

### 4.1 编码原则

1. 业务编码应能区分批次类型；
2. 同一设备或罐体在同一天重复使用时必须唯一；
3. 业务编码用于展示和操作，不作为数据库唯一技术主键；
4. 数据库使用不可变UUID或内部流水号；
5. 批次边界修正时不修改内部主键，通过版本记录保存变化。

### 4.2 建议编码

| 批次类型 | 建议编码 | 示例 |
| --- | --- | --- |
| 供应商原料批次 | 沿用供应商编码 | `SUP-20260801-A` |
| 入厂车辆批次 | `RM-日期-当日车次-供应商` | `RM-260810-001-S001` |
| 投料逻辑批次 | `FEED-日期-入口时间-序号` | `FEED-260810-0800-01` |
| 糖化罐批次 | `TH-日期-罐号-罐次` | `TH-260810-03-001` |
| F42逻辑批次 | `F42-日期-入口时间-序号` | `F42-260810-0800-01` |
| F90逻辑批次 | `F90-日期-入口时间-序号` | `F90-260810-1000-01` |
| F55混合批次 | `MIX-产品-日期-入口时间-序号` | `MIX-F55-260810-1200-01` |
| QC罐批次 | `QC-日期-罐号-进料序号` | `QC-260810-Q03-01` |
| 成品罐批次 | `FG-日期-罐号-进料序号` | `FG-260810-F001-01` |
| 装车批次 | `SHIP-日期-成品罐-装车序号` | `SHIP-260810-F001-01` |

平面库和线边原则上不重新生成批次编码，通过原料批次号与位置记录表示。确需拆分形成子批时，可增加子批序号，例如`RM-260810-001-S001-02`。

## 5. 各节点详细划分方案

### 5.1 供应商原料批次

#### 生成规则

沿用供应商提供的生产批次号，关联供应商、生产日期、包装规格、质量报告和袋装标识。

#### 特殊处理

一辆车同时装载多个供应商批次时，不合并供应商批次。系统创建一个入厂车辆批次，并通过数量关系关联多个供应商批次。

示例：

```text
供应商批次A 18吨 ─┐
                    ├→ 入厂车辆批次RM001 36吨
供应商批次B 18吨 ─┘
```

### 5.2 入厂车辆批次

#### 生成规则

车辆识别或首次过磅后预生成批次，完成卸货、空车回磅和质量确认后转为正式状态。

#### 数量依据

- 主依据：地磅净重；
- 核对依据：袋数×包装规格；
- 差异超过阈值时进入待复核状态。

#### 去向处理

支持两种实际路径：

```text
入厂车辆批次 → 平面库
入厂车辆批次 → 线边工位
```

不要求为直送线边虚构平面库出入库记录。

### 5.3 平面库与线边库存

#### 核心规则

原料从平库移动到线边时，默认不产生新正式批次，只更新批次库存余额并记录移库事件。

示例：

```text
RM001在K001：36吨
移库事件：K001 → XB01，10吨

移库后：
RM001/K001 = 26吨
RM001/XB01 = 10吨
```

#### 需要生成子批的情况

- 一个来源批次被拆分后需要独立冻结或检验；
- 不同来源批次发生物理混合且无法保持原包装标识；
- 重新包装；
- 质量状态发生局部变化；
- 业务明确要求独立管理。

### 5.4 投料逻辑批次

#### 批次入口

以物料进入投料口的时间和累计投料量为准。系统记录各来源原料批次的实际消耗数量。

#### 正常生成方式

可配置基础入口窗口，例如两小时，但基础窗口只是管理粒度，不代表整批物料同时到达下游。

#### 强制断批事件

- 产品或配方变化；
- 原料类型变化；
- 投料中断超过阈值；
- 产线清洗或排空；
- 人工质量隔离；
- 设备或管道切换；
- 业务人工确认断批。

#### 与糖化罐关联

通过糖化罐进料阀切换时间和入口累计流量，建立多对多关系。

示例：

| 投料批次 | 糖化批次 | 转入量 | 时间范围 |
| --- | --- | ---: | --- |
| FEED-01 | TH02-001 | 40t | 08:00—08:45 |
| FEED-01 | TH03-001 | 20t | 08:45—09:05 |
| FEED-02 | TH03-001 | 80t | 09:05—10:20 |

### 5.5 糖化罐物理批次

#### 生成规则

糖化罐进料阀打开时生成批次，完整记录进料、糖化、检验和出料过程。一次独立进料和完整出料对应一个糖化批次。

#### 结束规则

本次出料完成且出口阀关闭后结束。若残留物料继续参与下一批，应记录残留转移关系，不能直接忽略。

#### 数量依据

建议优先级：

1. 入口和出口累计流量；
2. 经标定的罐液位×密度；
3. 人工核定值。

系统同时保留不同计量结果，并对差异进行校验。

### 5.6 F42连续流批次

#### 批次入口

以糖化罐出料进入F42连续处理段的时间及累计量为入口依据。

#### 追踪方式

采用累计量匹配，不仅依赖平均时间平移。

```text
出口对应入口累计量
≈ 出口累计量 + 当前工艺段有效持液量
```

当存在损耗、回流或有效持液量变化时增加修正项：

```text
等效入口累计量
= 出口累计量
+ 当前有效持液量
+ 累计损耗
- 回流修正
```

#### 分流处理

F42进入色谱和直接进入F55时分别生成物料转移事件：

```text
F42-01 → F90-01：60吨
F42-01 → MIX-F55-01：40吨
```

### 5.7 F90色谱逻辑批次

#### 生成规则

F42物料进入色谱入口时生成F90逻辑批次，记录来源F42批次、投入量、树脂批次、设备参数、产出量和收率。

#### 结束规则

入口窗口正常结束或发生以下事件时结束：

- 色谱运行周期切换；
- 树脂或工艺参数发生关键变化；
- 停机超过阈值；
- 清洗、排空；
- 质量异常；
- 去向管道切换。

### 5.8 F55混合逻辑批次

#### 生成规则

F90和F42开始按同一配方进入F55混合器时生成批次。

每个批次至少记录：

- 来源F90批次和投入量；
- 来源F42批次和投入量；
- 实际混合比例；
- 产品类型；
- 配方编号及版本；
- 入口起止时间；
- 出口累计量；
- 去向QC罐。

#### 强制断批事件

- F90:F42目标比例变化；
- 实际比例持续超差；
- F55、F60或定制产品切换；
- 配方版本变化；
- 清洗或排空；
- 长时间停机；
- 返料加入；
- 质量隔离。

#### 终点建议

统一以QC罐进料阀作为追溯终点。F55蒸发器出口作为中间计量点，其至QC罐入口的管道持液量纳入连续流模型。

### 5.9 QC罐物理批次

#### 生成规则

QC罐进料阀打开时生成新批次，编码必须包含进料序号。进料完成、取样、检验、调整和出料均记录在该批次下。

#### 调整和不合格处理

- 未改变物料组成的重复检验不生成新批；
- 补料、返料或配方调整导致组成变化时生成新版本或新批次；
- 不合格批次保留原批次号和状态，不从追溯链删除；
- 转入其他工序时记录返料事件。

### 5.10 成品罐物理批次

成品罐需要根据现场运行方式选择模型。

#### 模式A：空罐建批

适用于罐体每批清空或清洗后重新进料：

```text
空罐或清洗完成
→ 首次进料生成成品罐批次
→ 一个或多个合格QC批次转入
→ 全部出完或清罐后结束
```

该模式边界最清晰，优先推荐。

#### 模式B：非空罐续加

若允许罐内有余量时继续加入新批次，则采用批次余额账。

示例：

```text
原有A：200吨
加入B：100吨
完全混合后总量：300吨
装车：30吨
```

按完全混合模型：

```text
车辆来源A = 30 × 200/300 = 20吨
车辆来源B = 30 × 100/300 = 10吨

装车后余额：
A = 180吨
B = 90吨
```

若现场并非完全混合，需要通过工艺验证确定分层、先进先出或其他模型。

### 5.11 装车/发货物理批次

#### 生成规则

成品罐出口阀向指定车辆打开时生成装车批次，装车结束、地磅确认、质量放行后完成。

#### 必要数据

- 来源成品罐及批次组成；
- 装车开始和结束时间；
- 流量计累计量；
- 地磅净重；
- 车牌、挂车、槽罐和铅封号；
- 订单、客户和承运商；
- 出厂检验及放行结果。

若成品罐内包含多个来源批次，按成品罐采用的混合模型计算车辆来源组成。

## 6. 连续流追踪算法

### 6.1 旧方法

旧方法采用：

```text
过程时间 = 设备及管道有效容积 ÷ 平均流量
```

然后将入口批次整体平移到出口。

该方法简单，但当流量变化、设备回流、停机或持液量变化时，前后部分物料的实际到达时间不同，整体平移会产生较大误差。

### 6.2 新方法：累计量匹配

系统持续记录工艺段入口和出口累计量，并维护当前有效持液量。

某入口批次占用的累计量范围为：

```text
[入口累计量起点，入口累计量终点]
```

出口物料通过有效持液量换算回入口累计量区间，从而判断其来源批次。

该方法在流量变化时仍可连续推进，不需要不断修改已生成的入口批次。

### 6.3 过渡区贡献比例

批次切换附近设置过渡区，不强行100%归入单一批次。

示例：

| 出口时间 | 上一批贡献 | 下一批贡献 | 追溯含义 |
| --- | ---: | ---: | --- |
| 10:00—10:05 | 80% | 20% | 以上一批为主，两批均可能影响 |
| 10:05—10:10 | 50% | 50% | 两批共同影响 |
| 10:10—10:15 | 20% | 80% | 以下一批为主，两批均可能影响 |
| 10:15以后 | 0% | 100% | 归属下一批 |

贡献比例可采用以下方式确定：

1. 历史生产数据拟合；
2. 示踪实验；
3. 在线浓度或质量指标变化；
4. 经业务确认的经验曲线。

### 6.4 不同业务用途的处理

| 用途 | 使用规则 |
| --- | --- |
| 质量召回 | 采用保守范围，将核心批次及过渡区批次全部列入可能影响范围 |
| 批次成本 | 按投入量或贡献比例分配 |
| 日常生产展示 | 显示主要来源批次和贡献比例 |
| 审计复核 | 展示原始数据、算法版本、参数和人工修正记录 |

## 7. 数据置信度设计

每条批次关系增加数据依据和置信度。

| 等级 | 数据依据 | 示例 |
| --- | --- | --- |
| A | 直接自动计量和设备事件 | 地磅、流量计、阀门、罐次完整且一致 |
| B | 多个自动数据计算并通过平衡校验 | 流量累计与液位变化基本一致 |
| C | 单一仪表或模型估算 | 缺少出口流量，按入口流量和持液量推算 |
| D | 人工补录或异常估算 | 仪表中断后由业务人员补录 |

追溯结果应显示置信度。质量召回不得因为置信度低而缩小范围，必要时应扩大可能影响批次。

## 8. 物料平衡与修正机制

### 8.1 平衡公式

各工艺段按统一口径校验：

```text
期初量 + 投入量
= 产出量 + 期末量 + 废料量 + 损耗量 ± 计量差异
```

### 8.2 计量口径

需要统一：

- 湿基吨；
- 绝干吨；
- 质量流量与体积流量；
- 密度取值时间；
- 固形物浓度；
- 罐容标定表；
- 正常损耗和仪表误差。

### 8.3 超差处理

1. 系统自动生成超差预警；
2. 检查流量、液位、阀门和密度数据；
3. 业务人员选择原因；
4. 必要时录入调整事件；
5. 保留原计算结果、调整值、原因和审批；
6. 不直接覆盖历史数据。

## 9. 异常场景解决方案

| 场景 | 处理方案 |
| --- | --- |
| 短时流量波动 | 不断批，累计量模型自动调整下游到达时间 |
| 流量归零 | 暂停累计；超过阈值后结束当前逻辑批次 |
| 设备停机但未排空 | 保留管内持液量，恢复后可继续原批；是否断批由停机阈值和质量规则决定 |
| 清洗或管道排空 | 强制结束当前批次，记录清洗事件和排放量 |
| 配方/产品切换 | 强制结束当前批次，切换料进入过渡区或独立过渡批次 |
| 流量计缺数 | 优先使用其他仪表和物料平衡估算，标记低置信度并要求确认 |
| 阀门时间错误 | 生成边界修正版本，保留原记录和修正原因 |
| QC不合格 | 冻结批次；返料、调整、降级或报废均生成事件 |
| 返料加入 | 强制断批或生成新版本，建立原批次至新批次的数量关系 |
| 成品罐非空续加 | 使用批次余额账，不把全部装车量归入最新进料批次 |
| 批次作废 | 保留批次和关系，标记作废并关联替代批次 |

## 10. 系统职责划分

| 系统 | 主要职责 |
| --- | --- |
| 门禁/TMS | 车辆识别、到厂离厂时间、承运信息 |
| 地磅 | 毛重、皮重、净重、装车重量 |
| WMS/WCS | 库位、线边库存、移库、包装库存、发货库存 |
| MES | 工单、产品、批次状态、配方、生产事件、人工确认 |
| DCS/PLC | 流量、液位、温度、压力、阀门、设备启停和罐次事件 |
| QMS/LIMS | 取样、检验、质量状态、放行、冻结和不合格处置 |
| SAP | 物料、订单、采购、销售及财务成本权威数据 |
| SCOS | 跨系统批次谱系、连续流计算、影响分析、成本传递和可视化 |

正常批次应尽量由设备和业务事件自动生成。人工主要用于异常确认、规则选择、补录和审批。

## 11. 新旧方案对比

| 对比项 | 旧方案：十级逐层建批 | 新方案：混合批次与物料账本 |
| --- | --- | --- |
| 总体结构 | 每层均倾向生成新批次 | 保留十级业务视图，底层按物理批次、逻辑批次、库存和事件建模 |
| 平库、线边 | 每次入库或移库可能生成新批次 | 原批次身份不变，记录位置和数量；必要时才生成子批 |
| 连续流边界 | 主要按容积÷平均流量整体平移 | 按入口批次、累计量、持液量和过渡比例追踪 |
| 流量变化 | 容易导致批次到达时间失真 | 累计量模型动态推进 |
| 批次切换 | 偏重固定时间窗口 | 时间窗口与配方、清洗、停机、阀门等事件共同决定 |
| 拆批并批 | 主要记录批次号关联 | 强制记录来源、去向、数量、时间和计量依据 |
| 成品罐续加 | 容易误归入最新批次 | 采用批次余额和混合模型 |
| 过渡料 | 边界处理不明确 | 设置过渡区贡献比例或独立过渡批次 |
| 返料回用 | 容易断链 | 作为正式物料转移事件进入谱系 |
| 异常批次 | 存在跳过追溯风险 | 永久保留谱系，仅改变状态和使用权限 |
| 数据精度 | 计算值容易表现为绝对事实 | 明确实测、计算、估算、补录及置信度 |
| 实施复杂度 | 表面简单，运行后异常修复困难 | 初期模型稍复杂，但运行稳定、可解释、可扩展 |
| 质量追溯 | 边界过窄时可能漏召回 | 区分确定影响和可能影响，支持保守召回 |
| 成本核算 | 缺少数量时难以准确传递 | 按实际数量或贡献比例传递成本 |

## 12. 新方案解决的主要问题

1. 避免将连续流批界描述为无法证明的绝对物理边界；
2. 解决流量变化后固定时间平移失真的问题；
3. 解决平库和线边重复建批、批次数量膨胀的问题；
4. 解决投料与糖化之间多对多关系丢失的问题；
5. 解决F42分流和F55汇流缺少数量的问题；
6. 解决成品罐非空续加时装车来源误判的问题；
7. 解决返料、甜水、过渡料和不合格调整的追溯断链问题；
8. 解决无效批次从追溯链消失的安全风险；
9. 解决系统估算结果缺少精度说明的问题；
10. 为批次质量影响分析和成本传递提供同一套数量基础。

## 13. 可实施性分析

### 13.1 可直接实施的部分

以下节点有明确业务或物理边界，可优先实施：

- 供应商原料批次；
- 入厂车辆批次；
- 原料库位和线边库存；
- 糖化罐批次；
- QC罐批次；
- 成品罐批次；
- 装车批次；
- 地磅、阀门、罐次和质量放行事件；
- 带数量的批次转移关系。

### 13.2 需要验证后实施的部分

- 投料至糖化入口的连续流追踪；
- 糖化出口至F42的累计量模型；
- F42分流与F90色谱追踪；
- F55混合及过渡区模型；
- 成品罐完全混合或分层模型；
- 过程损耗和计量误差参数。

### 13.3 实施前提

1. 确认批次控制点、仪表位号和流向；
2. 获取入口、出口流量及阀门事件；
3. 标定主要罐体、设备和管道有效持液量；
4. 确认物料密度、湿基和绝干折算口径；
5. 确认停机、清洗、换品和配方切换规则；
6. 确认成品罐是否允许非空续加；
7. 完成历史数据回放或现场示踪验证；
8. 确认各工艺段物料平衡允许误差。

## 14. 分阶段实施建议

### 第一阶段：物理批次与物料账本

实施范围：

- 供应商、入厂、糖化、QC、成品罐和装车批次；
- 原料库存余额；
- 物料转移事件；
- 拆批、并批和混罐数量；
- 质量检验、冻结和放行；
- 基础正向和反向追溯。

目标：先形成可靠的物理节点追溯闭环。

### 第二阶段：连续流追踪

实施范围：

- 投料、F42、F90和F55逻辑批次；
- 入口和出口累计量；
- 有效持液量模型；
- 过渡区比例；
- 置信度和可能影响范围；
- 停机、清洗和换品事件。

目标：将物理批次之间的连续生产过程连接起来。

### 第三阶段：批次成本与优化分析

实施范围：

- 上游材料成本按数量传递；
- 辅料、能源和设备作业成本归集；
- 返料、损耗、副产品和废弃物处理；
- 费用池分摊；
- SAP月结差异调整；
- 批次、产品、订单和客户盈利分析。

目标：在批次谱系和数量关系稳定后实现精细成本核算。

## 15. 验收建议

### 15.1 功能验收

- 任一装车批次可反向追溯至成品罐、QC罐、F55、F90/F42、糖化、投料和供应商原料；
- 任一原料批次可正向追溯至在制品、成品库存、装车、订单和客户；
- 拆批、并批、返料和混罐均可展示数量；
- 无效、冻结和作废批次仍可查询完整历史；
- 规则修正前后版本均可回放。

### 15.2 数据验收

- 关键物理批次的进出料事件完整；
- 物料平衡误差在业务确认范围内；
- 连续流到达时间与历史数据或现场测试基本一致；
- 仪表中断场景可以降级计算并显示低置信度；
- 成品罐续加和多批次装车来源计算正确。

### 15.3 场景验收

至少验证：

1. 入厂原料直送线边；
2. 一个原料批次拆分到多个位置；
3. 多个投料批次进入一个糖化罐；
4. 投料期间发生糖化罐阀门切换；
5. F42分流至F90和F55；
6. F90与F42多批次混合；
7. F55配方中途变化；
8. 连续段短时停机和流量波动；
9. QC不合格返料；
10. 成品罐非空续加后装车；
11. 流量计数据缺失；
12. 批次边界事后修正；
13. 从客户投诉反向追溯；
14. 从异常原料正向计算影响范围。

## 16. 结论

旧十级批次方案可作为业务理解和展示框架，但不建议原样作为系统底层模型。其主要问题是对连续流批界过度精确、位置移动重复建批、拆批并批缺少数量，以及对混罐、返料和过渡料支持不足。

新方案通过“物理批次、连续流逻辑批次、库存余额、物料转移事件、累计量追踪、过渡区比例和数据置信度”组合建模，在保留业务可理解性的同时，提高了现场可实施性、追溯可靠性和成本核算基础。

本方案并不承诺连续流中不存在误差，而是确保每个结果都有数据依据、计算方法、精度说明和可审计记录。对于质量风险，系统采用保守的可能影响范围；对于成本核算，系统采用实际数量或贡献比例。该方法比简单按固定时间或平均停留时间逐层硬切更适合实际果葡糖浆连续生产线。
