# 果葡糖浆生产工艺与批次划分说明

## 1. 文档目的

本文用于沉淀果葡糖浆生产线的工艺流程、物料流转关系和批次划分方法，为后续业务蓝图、批次追溯、批次成本核算、质量影响分析、生产执行接口及系统功能设计提供统一基础。

本文重点回答以下问题：

1. 玉米淀粉如何从入厂、仓储、投料转化为果葡糖浆成品；
2. 哪些工序属于离散物流，哪些属于连续生产，哪些具有天然物理批界；
3. 各层批次在什么节点生成、何时结束、如何编码；
4. 连续生产过程中如何利用流量、设备容积和时间窗口划分逻辑批次；
5. 分流、汇流、混罐、装车等场景下如何保持上下游批次关系；
6. 批次模型需要记录哪些数量、时间、设备、质量和状态数据。

## 3. 核心理解

果葡糖浆产线不是单一的离散生产或连续生产，而是由三类生产形态组合形成：

| 生产形态 | 典型区域 | 主要特征 | 适宜的批次划分方法 |
| --- | --- | --- | --- |
| 离散物流 | 车辆入厂、卸货、平库、线边、装车 | 有明确车辆、托盘、库位、工位和业务操作事件 | 按供应商批次、车次、库位、工位、装车次序划分 |
| 连续生产 | 溶粉、液化、过滤、离交、异构、色谱、混合、蒸发 | 物料在管道和设备中连续流动，前后物料首尾相接或发生混合 | 按入口时间窗口划分，并根据设备有效容积和实际流量计算过程时间 |
| 罐式间歇生产 | 糖化罐、QC罐、成品罐 | 具有明确进料、停留、检验和出料过程，可由阀门事件确定边界 | 按罐号和每次完整进出料事件划分 |

因此，果葡糖浆批次体系必须同时支持：

- 离散事件批次；
- 罐次物理批次；
- 连续流时间切片批次；
- 一个上游批次拆分至多个下游批次；
- 多个上游批次汇入一个下游批次；
- 通过数量、时间和设备事件建立批次谱系。

只保存批次号之间的文字关联，无法满足精确追溯、质量影响范围计算和批次成本核算。每条批次关系必须同时记录实际数量和时间依据。

## 4. 工艺流程概览

### 4.1 主流程

```text
供应商玉米淀粉批次
        ↓
车辆识别、过磅、检验、卸货
        ↓
入厂原料批次
        ├─→ 158平面库库位批次 ─→ 线边工位批次
        └──────────────────→ 线边工位批次
                                    ↓
                              拆包与投料口
                                    ↓
                        溶粉、淀粉乳、管道调浆
                                    ↓
                                  液化
                                    ↓
                             12个并列糖化罐
                                    ↓
                 膜过滤、脱色、过滤、离交、蒸发
                                    ↓
                                  异构
                                    ↓
                     F42脱色、过滤、离子交换
                                    ↓
                             F42中间品节点
                              ┌─────┴─────┐
                              │           │
                         部分F42      F42蒸发、色谱
                              │           ↓
                              │         F90糖浆
                              └─────┬─────┘
                                    ↓
                                F55混合
                                    ↓
                 冰水换热、混床、密闭过滤、减菌过滤
                                    ↓
                                F55蒸发
                                    ↓
                                  QC罐
                                    ↓
                                 成品罐
                                    ↓
                             槽车装车与发运
```

### 4.2 批次链概览

```text
供应商原料批次
  ↓
入厂原料批次
  ├─→ 平面库库位批次 ─→ 线边工位批次
  └────────────────→ 线边工位批次
                           ↓
多个原料批次 ───────→ 投料批次
                           ↓
多个投料批次 ───────→ 糖化批次
                           ↓
糖化批次 ───────────→ F42中间品批次
                           ├─→ F90色谱分离批次 ─┐
                           └─────────────────┤
                                              ↓
                                         F55混合批次
                                              ↓
                                          QC罐批次
                                              ↓
                                   一个或多个QC罐批次
                                              ↓
                                         成品罐批次
                                              ↓
                                      多个车次批次
```

## 5. 工艺流水线分段说明

### 5.1 原料入厂与仓储

玉米淀粉以袋装形式由车辆运输至厂区。车辆经过信息识别、过磅、检验和卸货后，物料可进入158平面库，也可根据生产需要直接送至线边。

主要业务节点包括：

1. 车辆入厂识别；
2. 毛重过磅；
3. 到货检验和放行；
4. 卸货；
5. 平面库库位分配或线边工位分配；
6. 空车回磅；
7. WMS登记实际库存位置和数量。

该区域的批次划分依据是供应商批次、车辆、到厂日期、库位及线边工位，属于典型离散物流批次。

### 5.2 拆包、投料与溶粉

线边玉米淀粉由叉车按序补料，经拆包机或人工辅助破袋进入投料口。物料按比例加入工艺水，在果糖组溶粉罐中形成淀粉乳，再进入淀粉乳罐和淀粉乳接收罐。

该区域需要关注：

- 多个原料批次可能按先进先出顺序连续投料；
- 一个原料批次可能跨越多个投料时间窗口；
- 溶粉罐内可能发生物理混合；
- 淀粉乳通过质量流量计计量；
- 投水可能使用甜水，甜水不足时补充自来水。

因此，投料批次必须记录每个来源原料批次的实际投料数量，而不能只关联一个原料批次号。

### 5.3 液化

淀粉乳经管道调浆后进入液化段，主要经过：

```text
一次喷射前罐
→ 换热
→ 一次喷射器
→ 时间压力维持段
→ 一次闪蒸罐
→ 层流罐
→ 二闪罐
→ 换热
```

液化过程中加入α淀粉酶，并采集温度、压力、pH、流量等过程参数。该段物料连续流动，没有稳定、清晰的单设备物理批界，因此与前端投料共同纳入投料时间批次。

### 5.4 糖化

液化液进入12个并列糖化罐，每个糖化罐独立完成进料、加酶加酸、搅拌、保温、取样、检验和出料。

糖化罐是整条果糖线第一个可靠的物理批次边界。糖化批次以具体糖化罐及每次完整出料为单位，不采用固定时间窗口。

需要记录：

- 进罐开始和结束时间；
- 进罐阀门切换记录；
- 来源投料批次及数量；
- 糖化罐编号；
- 酶和酸的实际投加量；
- 温度、pH、DE值、糖化时间；
- 出罐开始和结束时间；
- 液位、体积、密度和出罐重量；
- 质量结论。

### 5.5 糖化液净化、异构与F42形成

糖化液出罐后依次经过膜过滤、脱色、密闭过滤、袋式过滤、离子交换、蒸发和异构等连续工序，形成F42中间品。

主要工艺作用包括：

- 膜过滤：去除固形物和蛋白渣；
- 颗粒炭、硅藻土脱色：降低色值；
- 密闭过滤、袋式过滤：去除颗粒炭和过滤介质；
- 离子交换：去除离子杂质；
- 蒸发：提高固形物浓度；
- 异构：将部分葡萄糖转化为果糖；
- F42后处理：进一步脱色、过滤和离交。

该段设备多、管道长、物料连续流动，采用动态时间切片形成F42中间品批次。

### 5.6 F42分流与F90色谱分离

F42中间品形成后出现分流：一部分F42直接参与F55混合，另一部分进入F42蒸发和色谱分离，形成高果糖浓度的F90糖浆。

这是典型拆批场景：

```text
一个F42中间品批次
├─ 数量A → F90色谱分离批次
└─ 数量B → F55混合批次
```

系统必须记录分流数量、分流时间、F90投入产出、收率、树脂批次及色谱运行参数。

### 5.7 F55混合及后处理

F55通过F90糖浆和部分F42糖浆按配方混合形成：

```text
F90糖浆 ─┐
          ├→ F55混合
部分F42 ─┘
```

混合后依次经过冰水换热、混床、密闭过滤、减菌过滤和F55蒸发，达到目标果糖含量、色值、固形物浓度和微生物要求。

这是典型并批场景。一个F55混合批次可能同时关联多个F90批次和多个F42批次，并记录各自实际投入数量。

配方比例或产品类型改变时，应强制结束当前批次并生成新批次。

### 5.8 QC罐、成品罐与发运

F55蒸发后进入QC罐进行质量检验。合格物料转入对应成品罐，不合格物料根据原因进行调整、返料、隔离或其他处置。

成品罐合格物料经出口阀和装车管线进入槽车，完成装车、称重、检验放行后形成最终发货批次。

该区域以进出料阀、罐号、装车开始结束时间和车牌号作为主要批次边界。

## 6. 十级批次划分体系

### 6.1 第1层：供应商原料批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 供应商生产的玉米淀粉批次 |
| 生成主体 | 供应商 |
| 生成时机 | 供应商完成生产或包装时 |
| 编码 | 沿用供应商批次号 |
| 起点 | 供应商生产或包装 |
| 终点 | 厂内入厂批次关联 |
| 主要作用 | 质量追溯起点、供应商评价 |

供应商批次应保存生产日期、包装规格、质量数据、供应商检验报告等信息。该层一般不产生厂内新增成本。

### 6.2 第2层：入厂原料批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 一次车辆到厂和卸货事件 |
| 生成时机 | 车辆入厂、完成识别或过磅后 |
| 编码格式 | `YYMMDD-序号-供应商ID` |
| 示例 | `260810-001-XXX` |
| 起点 | 车辆入厂 |
| 终点 | 实际卸货进入平面库或线边 |
| 主要作用 | 厂内成本归集起点、库存和追溯关联 |

如果一辆车包含多个供应商生产批次，应建立一个入厂批次与多个供应商子批次的数量关系，不能丢失供应商批次明细。

### 6.3 第2.1层：平面库库位批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 原料进入指定平面库库位的库存记录 |
| 生成时机 | 叉车完成入库或WMS确认入库时 |
| 编码格式 | `YYMMDD-序号-K库位号` |
| 示例 | `260810-001-K001` |
| 起点 | 入厂批次卸货 |
| 终点 | 从库位移出至线边或直接投料 |

一个入厂批次分到多个库位时，应生成多个库位批次，并分别记录重量。

### 6.4 第2.2层：线边工位批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 原料进入指定生产线边工位的库存记录 |
| 生成时机 | 叉车完成线边补料或入厂物料直接送达线边时 |
| 编码格式 | `YYMMDD-序号-XB工位号` |
| 示例 | `260810-001-XB01` |
| 起点 | 平面库移库或入厂直接送线边 |
| 终点 | 实际进入投料口 |

线边批次应允许两类来源：平面库库位批次或入厂原料批次。无论采用哪种路径，都必须保留原始入厂批次。

### 6.5 第3层：投料批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 投料口至糖化罐入口之间的连续物料时间窗口 |
| 生成时机 | 投料窗口开始时 |
| 编码格式 | `YYMMDD-W-HHMM` |
| 示例 | `260810-W-0800` |
| 起点 | 物料进入投料口 |
| 终点 | 液化液到达糖化罐入口阀 |
| 划分方法 | 动态时间切片 |

投料批次时间长度：

```text
Tw = 投料口至糖化罐入口的管道及设备有效容积
     ÷ 淀粉乳实际平均流量
```

物料以进入投料口的时间归属投料批次。上一个窗口的终点是下一个窗口的起点。

### 6.6 第4层：糖化批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 某个糖化罐的一次完整糖化和出料过程 |
| 生成时机 | 糖化罐开始进料或进料阀切换时 |
| 编码格式 | `YYMMDD-TH罐号-出料序号` |
| 示例 | `260810-TH03-001` |
| 起点 | 糖化罐进口阀 |
| 终点 | 糖化罐出口阀完成本次出料 |
| 划分方法 | 罐号和完整出料事件 |

糖化批次是第一个物理切分点，不依赖固定时间窗口。一个糖化批次可以接收多个投料批次，因此来源字段应为批次清单和数量明细，而不是单一批次号。

### 6.7 第5层：F42中间品批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 糖化罐出口至F42指定出口流量计之间的连续物料时间窗口 |
| 生成时机 | 糖化物料进入F42连续处理段时 |
| 编码格式 | `YYMMDD-F42-HHMM` |
| 示例 | `260810-F42-0800` |
| 起点 | 糖化罐出口阀 |
| 终点 | F42指定出口流量计 |
| 划分方法 | 动态时间切片 |

F42批次时间长度：

```text
Tf42 = 糖化罐出口至F42指定出口流量计之间的有效容积
       ÷ 该段实际平均流量
```

### 6.8 第6层：F90色谱分离批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 进入色谱分离并形成F90的连续物料时间窗口 |
| 生成时机 | F42物料进入色谱分离段时 |
| 编码格式 | `YYMMDD-F90-HHMM` |
| 示例 | `260810-F90-0800` |
| 起点 | 色谱分离段入口流量计 |
| 终点 | F55混合器入口调节阀 |
| 划分方法 | 动态时间切片 |

F90批次时间长度：

```text
Tf90 = 色谱分离段入口至F55混合器调节阀之间的有效容积
       ÷ 该段实际平均流量
```

### 6.9 第7层：F55混合批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | F90和F42按同一配方汇合后形成的连续物料时间窗口 |
| 生成时机 | F55混合入口窗口开始，或配方、产品发生切换时 |
| 编码格式 | `YYMMDD-H-HHMM` |
| 示例 | `260810-H-0800` |
| 起点 | F55混合器入口 |
| 终点 | F55蒸发器出口或QC罐进料阀，最终边界待统一 |
| 划分方法 | 动态时间切片，并受配方切换事件约束 |

F55段过程时间：

```text
Th = F55混合器至F55蒸发器出口的有效容积
     ÷ F55蒸发器出口实际平均流量
```

如果正式批次终点定义为QC罐进料阀，则还应加入F55蒸发器出口至QC罐进料阀的管道输送时间。

以下事件应强制结束当前F55混合批次并生成新批次：

- F90与F42混合比例变化；
- 产品类型变化；
- 配方或配方版本变化；
- 清洗后重新启动；
- 长时间停机、断料或流量归零；
- 质量隔离；
- 返料加入导致物料组成改变。

### 6.10 第8层：QC罐批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 某个QC罐的一次独立进料、检验和出料过程 |
| 生成时机 | QC罐进料阀打开时 |
| 建议编码 | `YYMMDD-Q罐号-进料序号` |
| 示例 | `260810-Q03-01` |
| 起点 | QC罐进料阀 |
| 终点 | QC罐本次出料完成 |
| 划分方法 | 罐号和完整进出料事件 |

同一QC罐在同一天重复使用时，必须通过进料序号区分不同批次。

### 6.11 第9层：成品罐批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 某成品罐的一次独立进料和存储过程 |
| 生成时机 | 成品罐开始接收合格QC罐物料时 |
| 建议编码 | `YYMMDD-F罐号-进料序号` |
| 示例 | `260810-F001-01` |
| 起点 | 成品罐进料阀 |
| 终点 | 清罐、换品或本次库存全部出完 |
| 划分方法 | 产品、罐号和进料事件 |

一个成品罐批次可能合并多个QC罐批次，必须保存每个QC批次的转入数量。只有在产品、质量状态和混罐规则允许时才能合罐。

### 6.12 第10层：车次批次

| 项目 | 定义 |
| --- | --- |
| 批次主体 | 某辆槽车的一次完整装车和交付 |
| 生成时机 | 成品罐出口阀向车辆开始装料时 |
| 编码格式 | `YYMMDD-F罐号-装车序号` |
| 示例 | `260810-F001-01` |
| 起点 | 成品罐出口阀 |
| 终点 | 装车结束、称重并放行 |
| 划分方法 | 每车每次装车独立划分 |

车次批次是散装果葡糖浆最终面向客户的交付批次，应关联车牌、槽罐号、铅封号、订单、客户、承运商、装车量、地磅重量、检验报告和质量放行信息。

## 7. 连续流批次划分原理

### 7.1 为什么需要时间切片

在连续生产段，物料在管道和设备中持续流动，相邻批次之间通常不存在可见的物理空隙。前一批物料和后一批物料可能首尾相接，并在部分设备内产生一定程度的混合。

因此，系统不能假设连续段存在绝对清晰的物理切断面，而应建立可解释、可计算、可追溯的逻辑批界。

### 7.2 基本计算原理

```text
过程时间 = 工艺段内设备和管道的有效容积 ÷ 实际平均体积流量
```

若流量采用质量流量，则需结合物料密度换算体积流量，或直接建立经现场标定的质量停留时间模型。

基本步骤为：

1. 在工艺段入口记录物料进入时间和入口批次号；
2. 累计入口流量，确定每个批次进入工艺段的数量；
3. 根据有效容积和实际流量计算过程时间；
4. 推算该入口批次到达出口的时间范围；
5. 将出口流量按时间范围归属至对应入口批次；
6. 根据出口流量累计计算该批次产出量；
7. 建立上游批次、下游批次和数量关系。

### 7.3 动态窗口而非固定窗口

“2小时一批”等固定时长可以作为初始业务规则或演示参数，但不能替代动态计算。以下情况会改变真实过程时间：

- 生产流量变化；
- 设备启停；
- 管道切换；
- 罐体液位变化；
- 物料密度和浓度变化；
- 回流或循环；
- 断料；
- 清洗和排空。

实际系统应保存每次计算所使用的设备有效容积、流量、密度、起止时间和规则版本，以便审计和回放。

### 7.4 批次边界处的过渡料

连续流批界附近可能存在过渡混合物料。建议业务规则明确以下一种处理方式：

1. 入口时间归属法：进入入口时即确定批次，后续混合不改变归属；
2. 比例拆分法：根据停留时间分布或流量比例将出口过渡量拆分给相邻批次；
3. 独立过渡批次法：将换品或配方切换期间的物料形成独立过渡批次；
4. 质量判定法：根据在线浓度或实验室检测结果判定切换点。

当前Excel规则主要采用入口时间归属法。正式实施前应由生产、质量和财务共同确认过渡料处理方法。

## 8. 批次关系类型

### 8.1 一对一传递

一个上游批次完整进入一个下游批次，例如某次独立QC罐物料全部转入一个空成品罐。

### 8.2 拆批

一个上游批次分为多个下游批次，例如：

- 一个入厂批次分到多个平面库库位；
- 一个库位批次分多次补到线边；
- 一个F42批次部分进入色谱、部分直接参与F55混合；
- 一个成品罐批次分装到多辆槽车。

### 8.3 并批

多个上游批次汇入一个下游批次，例如：

- 多个原料批次进入同一个投料窗口；
- 多个投料批次进入同一个糖化罐；
- F90和F42按配方形成一个F55混合批次；
- 多个QC罐批次转入同一个成品罐批次。

### 8.4 混批

多个来源批次在物理设备或储罐内不可逆混合。混批后仍应保留全部来源批次及投入数量，不得只保留最后一个来源批次。

### 8.5 返料与回流

不合格品、调整料、甜水或其他返料重新进入生产线时，应建立独立的返料关系：

```text
原批次 → 返料事件 → 进入节点 → 新批次
```

至少记录原批次、返料数量、返料原因、批准人、返入时间、返入工序和新批次号。

## 9. 关键批次触发节点

| 节点 | 触发事件 | 生成或结束的批次 |

## 10. 批次数据模型要求

### 10.1 批次主数据

每个批次至少包含：

- 批次号；
- 批次类型和层级；
- 产品或物料；
- 开始、结束时间；
- 数量和计量单位；
- 所在位置、工位、设备或罐号；
- 当前状态；
- 质量状态；
- 来源系统；
- 规则版本；
- 创建和确认人员。

### 10.2 批次关系数据

批次关系不应仅保存父批次号和子批次号，还应保存：

- 上游批次号；
- 下游批次号；
- 关系类型：消耗、产出、拆分、合并、转移、包装、发运、返料；
- 转移或投入数量；
- 关系开始和结束时间；
- 设备、管道、阀门或罐号；
- 流量计、液位计或地磅数据依据；
- 转化率、收率和损耗；
- 操作人和确认人；
- 数据来源系统。

### 10.3 过程数据

连续生产段应关联：

- 流量；
- 温度；
- 压力；
- 液位；
- 密度；
- pH；
- 浓度或固形物；
- 设备运行和停机状态；
- 阀门开关事件；
- 配方编号和版本；
- 清洗记录；
- 异常事件。

### 10.4 质量数据

批次应关联供应商检验、入厂检验、糖化检验、过程检验、QC检验和出厂检验，包括但不限于：

- 水分；
- 细度；
- 白度；
- 蛋白质；
- 灰分；
- 二氧化硫；
- DE值；
- 果糖含量；
- 干物质；
- 色值；
- pH；
- 电导率；
- 微生物；
- 检验报告和放行结论。

## 11. 异常场景处理原则

### 11.1 停机与断料

当入口流量归零或设备长时间停机时，应暂停当前时间窗口累计。停机超过业务阈值或重新启动前进行清洗时，应结束当前批次并生成新批次。

### 11.2 配方与产品切换

配方比例、产品类型或配方版本发生变化时，应立即形成新批次。切换过程中的过渡料应按已确认规则处理，不得直接归入切换前或切换后的正常批次而无记录。

### 11.3 不合格品

不合格批次不得删除或标记为不存在，应保留批次和全部谱系关系，并设置冻结、隔离、返料、降级、报废或调整状态。

### 11.4 清洗和交接料

清洗事件应作为批次边界事件记录。清洗水、甜水和交接料如进入后续生产，应明确其物料属性、数量和来源批次。

### 11.5 计量缺失或异常

当流量计、液位计或阀门状态缺失时，系统应保留异常标识，并按经审批的降级方法估算，不应把估算数据标记为实际测量数据。

## 12. 与成本核算和质量追溯的关系

批次划分既服务于质量追溯，也服务于批次成本核算。

每层批次成本可表示为：

```text
本层批次成本
= 按实际投入数量转入的上游批次成本
+ 本工艺段可直接归集的材料、能源和作业成本
+ 按成本动因分摊的间接费用
- 副产品或可回收物料的成本抵减
```

通过批次谱系可以回答：

- 某车成品来自哪些成品罐、QC罐、F55、F90、F42、糖化、投料和原料批次；
- 某个供应商原料批次影响了哪些在制品、库存、车辆、订单和客户；
- 某个批次成本异常产生在哪个工艺段；
- F42分流、F55混合和成品合罐时成本如何按数量传递；
- 返料、损耗、废水、蛋白渣等如何影响批次成本。

## 13. 现有规则中的待确认事项

以下内容尚需结合DCS、MES、WMS、QMS、现场设备台账及业务访谈进一步确认：

1. 入厂物料是否允许稳定、常态化地直接送线边；
2. 同一库位是否允许存放多个供应商批次，混放时如何记录；
3. 投料批次是否以动态`Tw`为准，还是保留固定业务窗口；
4. 投料口至糖化罐入口的设备有效容积、密度和流量取值点；
5. F42批次终点流量计`FT120101`的现场准确位置；
6. F90批次入口流量计`FT120103`的现场准确位置和含义；
7. F55混合批次的正式终点是F55蒸发器出口还是QC罐进料阀；
8. F55蒸发器出口至QC罐进料阀之间的输送时间是否计入`Th`；
9. QC罐是否可能同日重复使用，以及进料序号的正式编码规则；
10. 成品罐批次是否增加进料序号；
11. 多个QC罐合入成品罐的业务条件和质量审批规则；
12. 配方切换、换品、清洗和过渡料的划分规则；
13. 不合格品返料、甜水回用和其他回流物料的批次关联方式；
14. 计量缺失时允许采用的估算方法和审批要求；
15. 各工艺段合理的停机断批阈值；
16. 批次规则、设备容积和计算参数的版本管理及生效机制。

## 14. 建议的系统实现原则

1. **入口定批**：连续段原则上以物料进入工艺段入口的时间确定批次归属；
2. **数量守恒**：每次拆批和并批均记录实际数量，并进行投入、产出、损耗平衡校验；
3. **事件留痕**：阀门切换、配方变化、清洗、停机、返料和质量冻结均作为可追溯事件；
4. **物理批次优先**：存在可靠罐体或装车物理边界时，优先采用物理批次，不使用任意时间切片替代；
5. **动态时间切片**：连续工艺段基于有效容积和实际流量动态计算，不把固定时间作为唯一依据；
6. **谱系不丢失**：拆批、并批、混批和返料后仍保留全部来源和去向关系；
7. **规则可版本化**：批次编码、切片公式、设备容积和强制断批条件均应支持版本和生效日期；
8. **异常不覆盖**：估算、补录和人工修正数据必须标识来源、原因和审批记录；
9. **业务系统协同**：WMS负责库存位置和移库事件，MES/DCS负责生产过程、流量、阀门和罐次，QMS/LIMS负责质量检验，SAP提供成本权威数据，SCOS负责跨系统批次谱系、分析和成本传递；
10. **追溯与成本同链**：质量追溯和成本核算应复用同一套批次关系和数量关系，避免形成两套不一致的批次链。
