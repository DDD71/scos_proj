## 采购计划输出数据描述

### 输出模块

| 模块         | 输出内容概述                                                 |
| ------------ | ------------------------------------------------------------ |
| 采购需求     | 各物料分周期的总需求、当前可用量和净需求                     |
| 推荐采购方案 | 采购供应商组合和各供应商的推荐采购数量（最优方案）           |
| 备选采购方案 | 可供业务人员比较选择的备选组合（次优方案，可以设置至多展示多少种） |
| 综合成本     | 采购成本、运输成本、账期节省和仓储成本                       |
| 不可行提示   | 无法满足采购需求的原因（例如供应商总产能不足、无符合要求的供应商等） |
